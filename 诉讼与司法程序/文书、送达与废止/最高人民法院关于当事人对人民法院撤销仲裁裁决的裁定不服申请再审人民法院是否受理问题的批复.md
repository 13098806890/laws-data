# 最高人民法院关于当事人对人民法院撤销仲裁裁决的裁定不服申请再审人民法院是否受理问题的批复

**分类**：司法解释  
**法律部门**：诉讼与非诉讼程序法  
**发布机关**：最高人民法院  
**发文字号**：法释〔1999〕6号  
**公布日期**：1999-02-11  
**生效日期**：1999-02-16

---

<a id="art-1"></a>最高人民法院  
关于当事人对人民法院撤销仲裁裁决的  
裁定不服申请再审人民法院  
是否受理问题的批复  
法释〔1999〕6号  
（1999年1月29日最高人民法院审判委员会第1042次会议通过　1999年2月11日最高人民法院公告公布　自1999年2月16日起施行）  
陕西省高级人民法院：  
你院陕高法〔1998〕78号《关于当事人对人民法院撤销仲裁裁决的裁定不服申请再审是否应当受理的请示》收悉。经研究，答复如下：  
根据[《中华人民共和国仲裁法》第九条](../../诉讼与司法程序/三大诉讼法/中华人民共和国仲裁法.md#art-9)规定的精神，当事人对人民法院撤销仲裁裁决的裁定不服申请再审的，人民法院不予受理。  
此复。

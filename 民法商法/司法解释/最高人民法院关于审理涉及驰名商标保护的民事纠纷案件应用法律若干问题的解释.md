### 正文

<a id="art-1"></a>第一条　本解释所称驰名商标，是指在中国境内为相关公众所熟知的商标。

<a id="art-6"></a>第六条　原告以被诉商标的使用侵犯其注册商标专用权为由提起民事诉讼，被告以原告的注册商标复制、摹仿或者翻译其在先未注册驰名商标为由提出抗辩或者提起反诉的，应当对其在先未注册商标驰名的事实负举证责任。

<a id="art-7"></a>第七条　被诉侵犯商标权或者不正当竞争行为发生前，曾被人民法院或者行政管理部门认定驰名的商标，被告对该商标驰名的事实不持异议的，人民法院应当予以认定。被告提出异议的，原告仍应当对该商标驰名的事实负举证责任。

<a id="art-8"></a>第八条　对于在中国境内为社会公众所熟知的商标，原告已提供其商标驰名的基本证据，或者被告不持异议的，人民法院对该商标驰名的事实予以认定。

<a id="art-9"></a>第九条　足以使相关公众对使用驰名商标和被诉商标的商品来源产生误认，或者足以使相关公众认为使用驰名商标和被诉商标的经营者之间具有许可使用、关联企业关系等特定联系的，属于[商标法第十三条](../../民法商法/中华人民共和国商标法.md#art-13)第二款规定的“容易导致混淆”。

<a id="art-12"></a>第十二条　当事人请求保护的未注册驰名商标，属于[商标法第十条](../../民法商法/中华人民共和国商标法.md#art-10)、第十一条、第十二条规定不得作为商标使用或者注册情形的，人民法院不予支持。

<a id="art-13"></a>第十三条　在涉及驰名商标保护的民事纠纷案件中，人民法院对于商标驰名的认定，仅作为案件事实和判决理由，不写入判决主文；以调解方式审结的，在调解书中对商标驰名的事实不予认定。

<a id="art-14"></a>第十四条　本院以前有关司法解释与本解释不一致的，以本解释为准。

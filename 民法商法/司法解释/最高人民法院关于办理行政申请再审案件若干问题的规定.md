# 最高人民法院关于办理行政申请再审案件若干问题的规定

**分类**：司法解释  
**法律部门**：民法商法  
**发文字号**：法释〔2021〕6号  
**公布日期**：2021-03-25  
**生效日期**：2021-04-01

> （2021年3月1日最高人民法院审判委员会第1833次会议通过，自2021年4月1日起施行）

---

### 正文

<a id="art-1"></a>第一条　当事人不服高级人民法院已经发生法律效力的判决、裁定，依照[行政诉讼法第九十条](../../诉讼与非诉讼程序法/中华人民共和国行政诉讼法.md#art-90)的规定向最高人民法院申请再审的，最高人民法院应当依法审查，分别情况予以处理。

<a id="art-4"></a>第四条　已经发生法律效力的判决、裁定认定事实清楚，适用法律、法规正确，当事人主张的再审事由不成立的，最高人民法院可以迳行裁定驳回再审申请。

<a id="art-5"></a>第五条　当事人不服人民法院再审判决、裁定的，可以依法向人民检察院申请抗诉或者检察建议。

<a id="art-6"></a>第六条　本解释自2021年4月1日起施行。本解释施行后，最高人民法院此前作出的相关司法解释与本解释相抵触的，以本解释为准。

### 第一章　总则

<a id="art-1"></a>第一条　为了全面推进高素质法官队伍建设，加强对法官的管理和监督，维护法官合法权益，保障人民法院依法独立行使审判权，保障法官依法履行职责，保障司法公正，根据宪法，制定本法。

<a id="art-2"></a>第二条　法官是依法行使国家审判权的审判人员，包括最高人民法院、地方各级人民法院和军事法院等专门人民法院的院长、副院长、审判委员会委员、庭长、副庭长和审判员。

<a id="art-3"></a>第三条　法官必须忠实执行宪法和法律，维护社会公平正义，全心全意为人民服务。

<a id="art-4"></a>第四条　法官应当公正对待当事人和其他诉讼参与人，对一切个人和组织在适用法律上一律平等。

<a id="art-5"></a>第五条　法官应当勤勉尽责，清正廉明，恪守职业道德。

<a id="art-6"></a>第六条　法官审判案件，应当以事实为根据，以法律为准绳，秉持客观公正的立场。

<a id="art-7"></a>第七条　法官依法履行职责，受法律保护，不受行政机关、社会团体和个人的干涉。

<a id="art-15"></a>第十五条　人民法院可以根据审判工作需要，从律师或者法学教学、研究人员等从事法律职业的人员中公开选拔法官。

### 第五章　法官的管理

<a id="art-25"></a>第二十五条　法官实行员额制管理。法官员额根据案件数量、经济社会发展情况、人口数量和人民法院审级等因素确定，在省、自治区、直辖市内实行总量控制、动态管理，优先考虑基层人民法院和案件数量多的人民法院办案需要。

<a id="art-26"></a>第二十六条　法官实行单独职务序列管理。

<a id="art-27"></a>第二十七条　最高人民法院院长为首席大法官。

<a id="art-28"></a>第二十八条　法官等级的确定，以法官德才表现、业务水平、审判工作实绩和工作年限等为依据。

<a id="art-29"></a>第二十九条　法官的等级设置、确定和晋升的具体办法，由国家另行规定。

<a id="art-30"></a>第三十条　初任法官实行统一职前培训制度。

<a id="art-31"></a>第三十一条　对法官应当有计划地进行政治、理论和业务培训。

<a id="art-32"></a>第三十二条　法官培训情况，作为法官任职、等级晋升的依据之一。

<a id="art-33"></a>第三十三条　法官培训机构按照有关规定承担培训法官的任务。

<a id="art-34"></a>第三十四条　法官申请辞职，应当由本人书面提出，经批准后，依照法律规定的程序免除其职务。

<a id="art-35"></a>第三十五条　辞退法官应当依照法律规定的程序免除其职务。

<a id="art-36"></a>第三十六条　法官从人民法院离任后两年内，不得以律师身份担任诉讼代理人或者辩护人。

<a id="art-37"></a>第三十七条　法官因工作需要，经单位选派或者批准，可以在高等学校、科研院所协助开展实践性教学、研究工作，并遵守国家有关规定。

### 第六章　法官的考核、奖励和惩戒

<a id="art-38"></a>第三十八条　人民法院设立法官考评委员会，负责对本院法官的考核工作。

<a id="art-39"></a>第三十九条　法官考评委员会的组成人员为五至九人。

<a id="art-40"></a>第四十条　对法官的考核，应当全面、客观、公正，实行平时考核和年度考核相结合。

<a id="art-41"></a>第四十一条　对法官的考核内容包括：审判工作实绩、职业道德、专业水平、工作能力、审判作风。重点考核审判工作实绩。

<a id="art-42"></a>第四十二条　年度考核结果分为优秀、称职、基本称职和不称职四个等次。

<a id="art-43"></a>第四十三条　考核结果以书面形式通知法官本人。法官对考核结果如果有异议，可以申请复核。

<a id="art-44"></a>第四十四条　法官在审判工作中有显著成绩和贡献的，或者有其他突出事迹的，应当给予奖励。

<a id="art-47"></a>第四十七条　法官涉嫌违纪违法，已经被立案调查、侦查，不宜继续履行职责的，按照管理权限和规定的程序暂时停止其履行职务。

<a id="art-48"></a>第四十八条　最高人民法院和省、自治区、直辖市设立法官惩戒委员会，负责从专业角度审查认定法官是否存在[本法第四十六条](#art-46)第四项、第五项规定的违反审判职责的行为，提出构成故意违反职责、存在重大过失、存在一般过失或者没有违反职责等审查意见。法官惩戒委员会提出审查意见后，人民法院依照有关规定作出是否予以惩戒的决定，并给予相应处理。

<a id="art-49"></a>第四十九条　法官惩戒委员会审议惩戒事项时，当事法官有权申请有关人员回避，有权进行陈述、举证、辩解。

<a id="art-50"></a>第五十条　法官惩戒委员会作出的审查意见应当送达当事法官。当事法官对审查意见有异议的，可以向惩戒委员会提出，惩戒委员会应当对异议及其理由进行审查，作出决定。

<a id="art-51"></a>第五十一条　法官惩戒委员会审议惩戒事项的具体程序，由最高人民法院商有关部门确定。

### 第七章　法官的职业保障

<a id="art-52"></a>第五十二条　人民法院设立法官权益保障委员会，维护法官合法权益，保障法官依法履行职责。

<a id="art-53"></a>第五十三条　除下列情形外，不得将法官调离审判岗位：

<a id="art-54"></a>第五十四条　任何单位或者个人不得要求法官从事超出法定职责范围的事务。

<a id="art-55"></a>第五十五条　法官的职业尊严和人身安全受法律保护。

<a id="art-56"></a>第五十六条　法官因依法履行职责遭受不实举报、诬告陷害、侮辱诽谤，致使名誉受到损害的，人民法院应当会同有关部门及时澄清事实，消除不良影响，并依法追究相关单位或者个人的责任。

<a id="art-57"></a>第五十七条　法官因依法履行职责，本人及其近亲属人身安全面临危险的，人民法院、公安机关应当对法官及其近亲属采取人身保护、禁止特定人员接触等必要保护措施。

<a id="art-58"></a>第五十八条　法官实行与其职责相适应的工资制度，按照法官等级享有国家规定的工资待遇，并建立与公务员工资同步调整机制。

<a id="art-59"></a>第五十九条　法官实行定期增资制度。

<a id="art-60"></a>第六十条　法官享受国家规定的津贴、补贴、奖金、保险和福利待遇。

<a id="art-61"></a>第六十一条　法官因公致残的，享受国家规定的伤残待遇。法官因公牺牲、因公死亡或者病故的，其亲属享受国家规定的抚恤和优待。

<a id="art-62"></a>第六十二条　法官的退休制度，根据审判工作特点，由国家另行规定。

<a id="art-63"></a>第六十三条　法官退休后，享受国家规定的养老金和其他待遇。

<a id="art-64"></a>第六十四条　对于国家机关及其工作人员侵犯[本法第十一条](#art-11)规定的法官权利的行为，法官有权提出控告。

<a id="art-65"></a>第六十五条　对法官处分或者人事处理错误的，应当及时予以纠正；造成名誉损害的，应当恢复名誉、消除影响、赔礼道歉；造成经济损失的，应当赔偿。对打击报复的直接责任人员，应当依法追究其责任。

### 第八章　附则

<a id="art-66"></a>第六十六条　国家对初任法官实行统一法律职业资格考试制度，由国务院司法行政部门商最高人民法院等有关部门组织实施。

<a id="art-67"></a>第六十七条　人民法院的法官助理在法官指导下负责审查案件材料、草拟法律文书等审判辅助事务。

<a id="art-68"></a>第六十八条　有关法官的权利、义务和管理制度，本法已有规定的，适用本法的规定；本法未作规定的，适用公务员管理的相关法律法规。

<a id="art-69"></a>第六十九条　本法自2019年10月1日起施行。

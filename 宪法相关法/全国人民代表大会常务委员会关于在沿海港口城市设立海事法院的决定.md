# 全国人民代表大会常务委员会关于在沿海港口城市设立海事法院的决定

**分类**：法律  
**法律部门**：宪法相关法  
**公布日期**：1984-11-14  
**生效日期**：1984-11-14

> （1984年11月14日第六届全国人民代表大会常务委员会第八次会议通过）

---

### 正文

<a id="art-1"></a>一、根据需要在沿海一定的港口城市设立海事法院。

<a id="art-2"></a>二、海事法院对所在地的市人民代表大会常务委员会负责。

<a id="art-3"></a>三、海事法院管辖第一审海事案件和海商案件，不受理刑事案件和其他民事案件。

<a id="art-4"></a>四、海事法院院长由所在地的市人民代表大会常务委员会主任提请本级人民代表大会常务委员会任免。

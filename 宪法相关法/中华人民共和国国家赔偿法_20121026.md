### 第一章　总则

<a id="art-1"></a>第一条　为保障公民、法人和其他组织享有依法取得国家赔偿的权利，促进国家机关依法行使职权，根据宪法，制定本法。

<a id="art-2"></a>第二条　国家机关和国家机关工作人员行使职权，有本法规定的侵犯公民、法人和其他组织合法权益的情形，造成损害的，受害人有依照本法取得国家赔偿的权利。&thinsp;<sup><a href="../民法商法/司法解释/最高人民法院关于审理行政赔偿案件若干问题的规定_20220320.md#art-2" title="被《最高人民法院关于审理行政赔偿案件若干问题的规定》第2条引用">[1]</a></sup>

#### 第二节　赔偿请求人和赔偿义务机关

<a id="art-6"></a>第六条　受害的公民、法人和其他组织有权要求赔偿。

<a id="art-7"></a>第七条　行政机关及其工作人员行使行政职权侵犯公民、法人和其他组织的合法权益造成损害的，该行政机关为赔偿义务机关。

<a id="art-8"></a>第八条　经复议机关复议的，最初造成侵权行为的行政机关为赔偿义务机关，但复议机关的复议决定加重损害的，复议机关对加重的部分履行赔偿义务。

#### 第三节　赔偿程序

<a id="art-9"></a>第九条　赔偿义务机关有[本法第三条](#art-3)、第四条规定情形之一的，应当给予赔偿。

<a id="art-10"></a>第十条　赔偿请求人可以向共同赔偿义务机关中的任何一个赔偿义务机关要求赔偿，该赔偿义务机关应当先予赔偿。

<a id="art-11"></a>第十一条　赔偿请求人根据受到的不同损害，可以同时提出数项赔偿要求。

<a id="art-12"></a>第十二条　要求赔偿应当递交申请书，申请书应当载明下列事项：&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于国家赔偿案件立案工作的规定_20120113.md#art-3" title="被《最高人民法院关于国家赔偿案件立案工作的规定》第3条引用">[1]</a></sup>

<a id="art-13"></a>第十三条　赔偿义务机关应当自收到申请之日起两个月内，作出是否赔偿的决定，赔偿义务机关作出赔偿决定，应当充分听取赔偿请求人的意见，并可以与赔偿请求人就赔偿方式、赔偿项目和赔偿数额依照本法第四章的规定进行协商。

<a id="art-14"></a>第十四条　赔偿义务机关在规定期限内未作出是否赔偿的决定，赔偿请求人可以自期限届满之日起三个月内，向人民法院提起诉讼。

<a id="art-15"></a>第十五条　人民法院审理行政赔偿案件，赔偿请求人和赔偿义务机关对自己提出的主张，应当提供证据。

<a id="art-16"></a>第十六条　赔偿义务机关赔偿损失后，应当责令有故意或者重大过失的工作人员或者受委托的组织或者个人承担部分或者全部赔偿费用。&thinsp;<sup><a href="../行政法/国家赔偿费用管理条例_20110117.md#art-12" title="被《国家赔偿费用管理条例》第12条引用">[1]</a></sup>

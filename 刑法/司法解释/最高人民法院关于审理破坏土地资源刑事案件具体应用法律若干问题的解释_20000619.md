# 最高人民法院关于审理破坏土地资源刑事案件具体应用法律若干问题的解释

**分类**：司法解释  
**法律部门**：刑法  
**发布机关**：最高人民法院  
**发文字号**：法释〔2000〕14号  
**公布日期**：2000-06-19  
**生效日期**：2000-06-22

> （2000年6月16日最高人民法院审判委员会第1119次会议通过　2000年6月19日最高人民法院公告公布　自2000年6月22日起施行）

---

### 正文

<a id="art-1"></a>第一条　以牟利为目的，违反土地管理法规，非法转让、倒卖土地使用权，具有下列情形之一的，属于非法转让、倒卖土地使用权“情节严重”，依照[刑法第二百二十八条](../../刑法/中华人民共和国刑法_20201226.md#art-228)的规定，以非法转让、倒卖土地使用权罪定罪处罚：

<a id="art-2"></a>第二条　实施第一条规定的行为，具有下列情形之一的，属于非法转让、倒卖土地使用权“情节特别严重”：

<a id="art-3"></a>第三条　违反土地管理法规，非法占用耕地改作他用，数量较大，造成耕地大量毁坏的，依照[刑法第三百四十二条](../../刑法/中华人民共和国刑法_20201226.md#art-342)的规定，以非法占用耕地罪定罪处罚：

<a id="art-4"></a>第四条　国家机关工作人员徇私舞弊，违反土地管理法规，滥用职权，非法批准征用、占用土地，具有下列情形之一的，属于非法批准征用、占用土地“情节严重”，依照[刑法第四百一十条](../../刑法/中华人民共和国刑法_20201226.md#art-410)的规定，以非法批准征用、占用土地罪定罪处罚：

<a id="art-5"></a>第五条　实施第四条规定的行为，具有下列情形之一的，属于非法批准征用、占用土地“致使国家或者集体利益遭受特别重大损失”：

<a id="art-6"></a>第六条　国家机关工作人员徇私舞弊，违反土地管理法规，非法低价出让国有土地使用权，具有下列情形之一的，属于“情节严重”，依照[刑法第四百一十条](../../刑法/中华人民共和国刑法_20201226.md#art-410)的规定，以非法低价出让国有土地使用权罪定罪处罚：

<a id="art-7"></a>第七条　实施第六条规定的行为，具有下列情形之一的，属于非法低价出让国有土地使用权，“致使国家和集体利益遭受特别重大损失”：

<a id="art-8"></a>第八条　单位犯非法转让、倒卖土地使用权罪、非法占有耕地罪的定罪量刑标准，依照[本解释第一条](#art-1)、第二条、第三条的规定执行。

<a id="art-9"></a>第九条　多次实施本解释规定的行为依法应当追诉的，或者1年内多次实施本解释规定的行为未经处理的，按照累计的数量、数额处罚。

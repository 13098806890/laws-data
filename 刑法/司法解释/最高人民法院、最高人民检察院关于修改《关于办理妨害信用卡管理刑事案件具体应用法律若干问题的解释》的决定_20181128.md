# 最高人民法院、最高人民检察院关于修改《关于办理妨害信用卡管理刑事案件具体应用法律若干问题的解释》的决定

**分类**：司法解释  
**法律部门**：刑法  
**发文字号**：法释〔2018〕19号  
**公布日期**：2018-11-28  
**生效日期**：2018-12-01

> 《最高人民法院、最高人民检察院关于修改〈关于办理妨害信用卡管理刑事案件具体应用法律若干问题的解释〉的决定》已于2018年7月30日由最高人民法院审判委员会第1745次会议、2018年10月19日由最高人民检察院第十三届检察委员会第七次会议通过，现予公布，自2018年12月1日起施行。

---

### 正文

<a id="art-1"></a>第一条　复制他人信用卡、将他人信用卡信息资料写入磁条介质、芯片或者以其他方法伪造信用卡一张以上的，应当认定为[刑法第一百七十七条](../../刑法/中华人民共和国刑法_20201226.md#art-177)第一款第四项规定的“伪造信用卡”，以伪造金融票证罪定罪处罚。

<a id="art-2"></a>第二条　明知是伪造的空白信用卡而持有、运输十张以上不满一百张的，应当认定为[刑法第一百七十七条](../../刑法/中华人民共和国刑法_20201226.md#art-177)之一第一款第一项规定的“数量较大”；非法持有他人信用卡五张以上不满五十张的，应当认定为[刑法第一百七十七条](../../刑法/中华人民共和国刑法_20201226.md#art-177)之一第一款第二项规定的“数量较大”。

<a id="art-3"></a>第三条　窃取、收买、非法提供他人信用卡信息资料，足以伪造可进行交易的信用卡，或者足以使他人以信用卡持卡人名义进行交易，涉及信用卡一张以上不满五张的，依照[刑法第一百七十七条](../../刑法/中华人民共和国刑法_20201226.md#art-177)之一第二款的规定，以窃取、收买、非法提供信用卡信息罪定罪处罚；涉及信用卡五张以上的，应当认定为[刑法第一百七十七条](../../刑法/中华人民共和国刑法_20201226.md#art-177)之一第一款规定的“数量巨大”。

<a id="art-4"></a>第四条　为信用卡申请人制作、提供虚假的财产状况、收入、职务等资信证明材料，涉及伪造、变造、买卖国家机关公文、证件、印章，或者涉及伪造公司、企业、事业单位、人民团体印章，应当追究刑事责任的，依照[刑法第二百八十条](../../刑法/中华人民共和国刑法_20201226.md#art-280)的规定，分别以伪造、变造、买卖国家机关公文、证件、印章罪和伪造公司、企业、事业单位、人民团体印章罪定罪处罚。

<a id="art-5"></a>第五条　使用伪造的信用卡、以虚假的身份证明骗领的信用卡、作废的信用卡或者冒用他人信用卡，进行信用卡诈骗活动，数额在五千元以上不满五万元的，应当认定为[刑法第一百九十六条](../../刑法/中华人民共和国刑法_20201226.md#art-196)规定的“数额较大”；数额在五万元以上不满五十万元的，应当认定为[刑法第一百九十六条](../../刑法/中华人民共和国刑法_20201226.md#art-196)规定的“数额巨大”；数额在五十万元以上的，应当认定为[刑法第一百九十六条](../../刑法/中华人民共和国刑法_20201226.md#art-196)规定的“数额特别巨大”。

<a id="art-6"></a>第六条　持卡人以非法占有为目的，超过规定限额或者规定期限透支，经发卡银行两次有效催收后超过三个月仍不归还的，应当认定为[刑法第一百九十六条](../../刑法/中华人民共和国刑法_20201226.md#art-196)规定的“恶意透支”。

<a id="art-7"></a>第七条　催收同时符合下列条件的，应当认定为[本解释第六条](#art-6)规定的“有效催收”：

<a id="art-8"></a>第八条　恶意透支，数额在五万元以上不满五十万元的，应当认定为[刑法第一百九十六条](../../刑法/中华人民共和国刑法_20201226.md#art-196)规定的“数额较大”；数额在五十万元以上不满五百万元的，应当认定为[刑法第一百九十六条](../../刑法/中华人民共和国刑法_20201226.md#art-196)规定的“数额巨大”；数额在五百万元以上的，应当认定为[刑法第一百九十六条](../../刑法/中华人民共和国刑法_20201226.md#art-196)规定的“数额特别巨大”。

<a id="art-9"></a>第九条　恶意透支的数额，是指公安机关刑事立案时尚未归还的实际透支的本金数额，不包括利息、复利、滞纳金、手续费等发卡银行收取的费用。归还或者支付的数额，应当认定为归还实际透支的本金。

<a id="art-10"></a>第十条　恶意透支数额较大，在提起公诉前全部归还或者具有其他情节轻微情形的，可以不起诉；在一审判决前全部归还或者具有其他情节轻微情形的，可以免予刑事处罚。但是，曾因信用卡诈骗受过两次以上处罚的除外。

<a id="art-11"></a>第十一条　发卡银行违规以信用卡透支形式变相发放贷款，持卡人未按规定归还的，不适用[刑法第一百九十六条](../../刑法/中华人民共和国刑法_20201226.md#art-196)‘恶意透支’的规定。构成其他犯罪的，以其他犯罪论处。

<a id="art-12"></a>第十二条　违反国家规定，使用销售点终端机具（POS机）等方法，以虚构交易、虚开价格、现金退货等方式向信用卡持卡人直接支付现金，情节严重的，应当依据[刑法第二百二十五条](../../刑法/中华人民共和国刑法_20201226.md#art-225)的规定，以非法经营罪定罪处罚。

<a id="art-13"></a>第十三条　单位实施本解释规定的行为，适用本解释规定的相应自然人犯罪的定罪量刑标准。

# 最高人民法院 最高人民检察院关于办理强奸、猥亵未成年人刑事案件适用法律若干问题的解释

**分类**：司法解释  
**法律部门**：刑法  
**发文字号**：法释〔2023〕3号  
**公布日期**：2023-05-24  
**生效日期**：2023-06-01

> （2023年1月3日最高人民法院审判委员会第1878次会议、2023年3月2日最高人民检察院第十三届检察委员会第一百一十四次会议通过，自2023年6月1日起施行）

---

### 正文

<a id="art-1"></a>第一条　奸淫幼女的，依照[刑法第二百三十六条](../../刑法/中华人民共和国刑法.md#art-236)第二款的规定从重处罚。具有下列情形之一的，应当适用较重的从重处罚幅度：

<a id="art-2"></a>第二条　强奸已满十四周岁的未成年女性或者奸淫幼女，具有下列情形之一的，应当认定为[刑法第二百三十六条](../../刑法/中华人民共和国刑法.md#art-236)第三款第一项规定的“强奸妇女、奸淫幼女情节恶劣”：

<a id="art-3"></a>第三条　奸淫幼女，具有下列情形之一的，应当认定为[刑法第二百三十六条](../../刑法/中华人民共和国刑法.md#art-236)第三款第五项规定的“造成幼女伤害”：

<a id="art-4"></a>第四条　强奸已满十四周岁的未成年女性或者奸淫幼女，致使其感染艾滋病病毒的，应当认定为刑法第二百三十六第三款第六项规定的“致使被害人重伤”。

<a id="art-5"></a>第五条　对已满十四周岁不满十六周岁的未成年女性负有特殊职责的人员，与该未成年女性发生性关系，具有下列情形之一的，应当认定为[刑法第二百三十六条](../../刑法/中华人民共和国刑法.md#art-236)之一规定的“情节恶劣”：

<a id="art-6"></a>第六条　对已满十四周岁的未成年女性负有特殊职责的人员，利用优势地位或者被害人孤立无援的境地，迫使被害人与其发生性关系的，依照[刑法第二百三十六条](../../刑法/中华人民共和国刑法.md#art-236)的规定，以强奸罪定罪处罚。

<a id="art-7"></a>第七条　猥亵儿童，具有下列情形之一的，应当认定为[刑法第二百三十七条](../../刑法/中华人民共和国刑法.md#art-237)第三款第三项规定的“造成儿童伤害或者其他严重后果”：

<a id="art-8"></a>第八条　猥亵儿童，具有下列情形之一的，应当认定为[刑法第二百三十七条](../../刑法/中华人民共和国刑法.md#art-237)第三款第四项规定的“猥亵手段恶劣或者有其他恶劣情节”：

<a id="art-9"></a>第九条　胁迫、诱骗未成年人通过网络视频聊天或者发送视频、照片等方式，暴露身体隐私部位或者实施淫秽行为，符合[刑法第二百三十七条](../../刑法/中华人民共和国刑法.md#art-237)规定的，以强制猥亵罪或者猥亵儿童罪定罪处罚。

<a id="art-10"></a>第十条　实施猥亵未成年人犯罪，造成被害人轻伤以上后果，同时符合[刑法第二百三十四条](../../刑法/中华人民共和国刑法.md#art-234)或者第二百三十二条的规定，构成故意伤害罪、故意杀人罪的，依照处罚较重的规定定罪处罚。

<a id="art-11"></a>第十一条　强奸、猥亵未成年人的成年被告人认罪认罚的，是否从宽处罚及从宽幅度应当从严把握。

<a id="art-12"></a>第十二条　对强奸未成年人的成年被告人判处刑罚时，一般不适用缓刑。

<a id="art-13"></a>第十三条　对于利用职业便利实施强奸、猥亵未成年人等犯罪的，人民法院应当依法适用从业禁止。

<a id="art-14"></a>第十四条　对未成年人实施强奸、猥亵等犯罪造成人身损害的，应当赔偿医疗费、护理费、交通费、营养费、住院伙食补助费等为治疗和康复支付的合理费用，以及因误工减少的收入。

<a id="art-15"></a>第十五条　本解释规定的“负有特殊职责的人员”，是指对未成年人负有监护、收养、看护、教育、医疗等职责的人员，包括与未成年人具有共同生活关系且事实上负有照顾、保护等职责的人员。

<a id="art-16"></a>第十六条　本解释自2023年6月1日起施行。

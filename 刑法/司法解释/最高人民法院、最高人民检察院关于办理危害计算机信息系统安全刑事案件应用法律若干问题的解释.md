# 最高人民法院、最高人民检察院关于办理危害计算机信息系统安全刑事案件应用法律若干问题的解释

**分类**：司法解释  
**法律部门**：刑法  
**发文字号**：法释〔2011〕19号  
**公布日期**：2011-08-01  
**生效日期**：2011-09-01

> 最高人民法院、最高人民检察院《关于办理危害计算机信息系统安全刑事案件应用法律若干问题的解释》已于2011年6月20日由最高人民法院审判委员会第1524次会议、2011年7月11日由最高人民检察院第十一届检察委员会第63次会议通过，现予公布，自2011年9月1日起施行。

---

### 正文

<a id="art-1"></a>第一条　非法获取计算机信息系统数据或者非法控制计算机信息系统，具有下列情形之一的，应当认定为[刑法第二百八十五条](../../刑法/中华人民共和国刑法.md#art-285)第二款规定的“情节严重”：

<a id="art-2"></a>第二条　具有下列情形之一的程序、工具，应当认定为[刑法第二百八十五条](../../刑法/中华人民共和国刑法.md#art-285)第三款规定的“专门用于侵入、非法控制计算机信息系统的程序、工具”：

<a id="art-3"></a>第三条　提供侵入、非法控制计算机信息系统的程序、工具，具有下列情形之一的，应当认定为[刑法第二百八十五条](../../刑法/中华人民共和国刑法.md#art-285)第三款规定的“情节严重”：

<a id="art-4"></a>第四条　破坏计算机信息系统功能、数据或者应用程序，具有下列情形之一的，应当认定为[刑法第二百八十六条](../../刑法/中华人民共和国刑法.md#art-286)第一款和第二款规定的“后果严重”：

<a id="art-5"></a>第五条　具有下列情形之一的程序，应当认定为[刑法第二百八十六条](../../刑法/中华人民共和国刑法.md#art-286)第三款规定的“计算机病毒等破坏性程序”：

<a id="art-6"></a>第六条　故意制作、传播计算机病毒等破坏性程序，影响计算机系统正常运行，具有下列情形之一的，应当认定为[刑法第二百八十六条](../../刑法/中华人民共和国刑法.md#art-286)第三款规定的“后果严重”：

<a id="art-7"></a>第七条　明知是非法获取计算机信息系统数据犯罪所获取的数据、非法控制计算机信息系统犯罪所获取的计算机信息系统控制权，而予以转移、收购、代为销售或者以其他方法掩饰、隐瞒，违法所得五千元以上的，应当依照[刑法第三百一十二条](../../刑法/中华人民共和国刑法.md#art-312)第一款的规定，以掩饰、隐瞒犯罪所得罪定罪处罚。

<a id="art-8"></a>第八条　以单位名义或者单位形式实施危害计算机信息系统安全犯罪，达到本解释规定的定罪量刑标准的，应当依照[刑法第二百八十五条](../../刑法/中华人民共和国刑法.md#art-285)、第二百八十六条的规定追究直接负责的主管人员和其他直接责任人员的刑事责任。

<a id="art-9"></a>第九条　明知他人实施[刑法第二百八十五条](../../刑法/中华人民共和国刑法.md#art-285)、第二百八十六条规定的行为，具有下列情形之一的，应当认定为共同犯罪，依照[刑法第二百八十五条](../../刑法/中华人民共和国刑法.md#art-285)、第二百八十六条的规定处罚：

<a id="art-10"></a>第十条　对于是否属于[刑法第二百八十五条](../../刑法/中华人民共和国刑法.md#art-285)、第二百八十六条规定的“国家事务、国防建设、尖端科学技术领域的计算机信息系统”、“专门用于侵入、非法控制计算机信息系统的程序、工具”、“计算机病毒等破坏性程序”难以确定的，应当委托省级以上负责计算机信息系统安全保护管理工作的部门检验。司法机关根据检验结论，并结合案件具体情况认定。

<a id="art-11"></a>第十一条　本解释所称“计算机信息系统”和“计算机系统”，是指具备自动处理数据功能的系统，包括计算机、网络设备、通信设备、自动化控制设备等。

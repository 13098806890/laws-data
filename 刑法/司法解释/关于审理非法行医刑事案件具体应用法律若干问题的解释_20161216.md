# 关于审理非法行医刑事案件具体应用法律若干问题的解释

**分类**：司法解释  
**法律部门**：刑法  
**发布机关**：最高人民法院  
**发文字号**：法释〔2016〕27号  
**公布日期**：2016-12-16  
**生效日期**：2016-12-20

> 最高人民法院《关于修改〈关于审理非法行医刑事案件具体应用法律若干问题的解释〉的决定》已于2016年12月12日由最高人民法院审判委员会第1703次会议通过，现予公布，自2016年12月20日起施行。

---

### 正文

<a id="art-1"></a>第一条　具有下列情形之一的，应认定为[刑法第三百三十六条](../../刑法/中华人民共和国刑法_20201226.md#art-336)第一款规定的“未取得医生执业资格的人非法行医”：

<a id="art-2"></a>第二条　具有下列情形之一的，应认定为[刑法第三百三十六条](../../刑法/中华人民共和国刑法_20201226.md#art-336)第一款规定的“情节严重”：

<a id="art-3"></a>第三条　具有下列情形之一的，应认定为[刑法第三百三十六条](../../刑法/中华人民共和国刑法_20201226.md#art-336)第一款规定的“严重损害就诊人身体健康”：

<a id="art-4"></a>第四条　非法行医行为系造成就诊人死亡的直接、主要原因的，应认定为[刑法第三百三十六条](../../刑法/中华人民共和国刑法_20201226.md#art-336)第一款规定的“造成就诊人死亡”。

<a id="art-5"></a>第五条　实施非法行医犯罪，同时构成生产、销售假药罪，生产、销售劣药罪，诈骗罪等其他犯罪的，依照刑法处罚较重的规定定罪处罚。

<a id="art-6"></a>第六条　本解释所称“医疗活动”“医疗行为”，参照《医疗机构管理条例实施细则》中的“诊疗活动”“医疗美容”认定。

# 最高人民法院、最高人民检察院关于办理非法制造、买卖、运输、储存毒鼠强等禁用剧毒化学品刑事案件具体应用法律若干问题的解释

**分类**：司法解释  
**法律部门**：刑法  
**发文字号**：法释〔2003〕14号  
**公布日期**：2003-09-04  
**生效日期**：2003-10-01

---

### 正文

<a id="art-1"></a>第一条　非法制造、买卖、运输、储存毒鼠强等禁用剧毒化学品，危害公共安全，具有下列情形之一的，依照[刑法第一百二十五条](../../刑法/中华人民共和国刑法.md#art-125)的规定，以非法制造、买卖、运输、储存危险物质罪，处三年以上十年以下有期徒刑：

<a id="art-2"></a>第二条　非法制造、买卖、运输、储存毒鼠强等禁用剧毒化学品，具有下列情形之一的，属于[刑法第一百二十五条](../../刑法/中华人民共和国刑法.md#art-125)规定的“情节严重”，处十年以上有期徒刑、无期徒刑或者死刑：

<a id="art-3"></a>第三条　单位非法制造、买卖、运输、储存毒鼠强等禁用剧毒化学品的，依照[本解释第一条](#art-1)、第二条规定的定罪量刑标准执行。

<a id="art-4"></a>第四条　对非法制造、买卖、运输、储存毒鼠强等禁用剧毒化学品行为负有查处职责的国家机关工作人员，滥用职权或者玩忽职守，致使公共财产、国家和人民利益遭受重大损失的，依照[刑法第三百九十七条](../../刑法/中华人民共和国刑法.md#art-397)的规定，以滥用职权罪或者玩忽职守罪追究刑事责任。

<a id="art-5"></a>第五条　本解释施行以前，确因生产、生活需要而非法制造、买卖、运输、储存毒鼠强等禁用剧毒化学品饵料自用，没有造成严重社会危害的，可以依照[刑法第十三条](../../刑法/中华人民共和国刑法.md#art-13)的规定，不作为犯罪处理。

<a id="art-6"></a>第六条　本解释所称“毒鼠强等禁用剧毒化学品”，是指国家明令禁止的毒鼠强、氟乙酰胺、氟乙酸钠、毒鼠硅、甘氟（见附表）。

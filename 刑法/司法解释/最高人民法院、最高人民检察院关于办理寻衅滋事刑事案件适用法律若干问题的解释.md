# 最高人民法院、最高人民检察院关于办理寻衅滋事刑事案件适用法律若干问题的解释

**分类**：司法解释  
**法律部门**：刑法  
**发文字号**：法释〔2013〕18号  
**公布日期**：2013-07-15  
**生效日期**：2013-07-22

> （2013年5月27日最高人民法院审判委员会第1579次会议、2013年4月28日最高人民检察院第十二届检察委员会第5次会议通过　2013年7月15日最高人民法院、最高人民检察院公告公布　自2013年7月22日起施行）

### 正文

<a id="art-1"></a>第一条　行为人为寻求刺激、发泄情绪、逞强耍横等，无事生非，实施[刑法第二百九十三条](../../刑法/中华人民共和国刑法.md#art-293)规定的行为的，应当认定为“寻衅滋事”。

<a id="art-2"></a>第二条　随意殴打他人，破坏社会秩序，具有下列情形之一的，应当认定为[刑法第二百九十三条](../../刑法/中华人民共和国刑法.md#art-293)第一款第一项规定的“情节恶劣”：

<a id="art-3"></a>第三条　追逐、拦截、辱骂、恐吓他人，破坏社会秩序，具有下列情形之一的，应当认定为[刑法第二百九十三条](../../刑法/中华人民共和国刑法.md#art-293)第一款第二项规定的“情节恶劣”：

<a id="art-4"></a>第四条　强拿硬要或者任意损毁、占用公私财物，破坏社会秩序，具有下列情形之一的，应当认定为[刑法第二百九十三条](../../刑法/中华人民共和国刑法.md#art-293)第一款第三项规定的“情节严重”：

<a id="art-5"></a>第五条　在车站、码头、机场、医院、商场、公园、影剧院、展览会、运动场或者其他公共场所起哄闹事，应当根据公共场所的性质、公共活动的重要程度、公共场所的人数、起哄闹事的时间、公共场所受影响的范围与程度等因素，综合判断是否“造成公共场所秩序严重混乱”。

<a id="art-6"></a>第六条　纠集他人三次以上实施寻衅滋事犯罪，未经处理的，应当依照[刑法第二百九十三条](../../刑法/中华人民共和国刑法.md#art-293)第二款的规定处罚。

<a id="art-7"></a>第七条　实施寻衅滋事行为，同时符合寻衅滋事罪和故意杀人罪、故意伤害罪、故意毁坏财物罪、敲诈勒索罪、抢夺罪、抢劫罪等罪的构成要件的，依照处罚较重的犯罪定罪处罚。

<a id="art-8"></a>第八条　行为人认罪、悔罪，积极赔偿被害人损失或者取得被害人谅解的，可以从轻处罚；犯罪情节轻微的，可以不起诉或者免予刑事处罚。

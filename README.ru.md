# База данных законов и нормативных актов Китая

[中文](README.md) · [English](README.en.md)

Структурированный набор данных действующих законов и нормативных актов КНР, включающий исходные документы (docx), структурированный JSON, базу данных SQLite и полные тексты в формате Markdown — для поиска, исследований и разработки приложений.

## Обзор данных

| Категория | Количество |
|-----------|-----------|
| Законы (法律) | 442 |
| Административные регламенты (行政法规) | 727 |
| Судебные толкования (司法解释) | 682 |
| Правовые толкования (法律解释) | 25 |
| Поправки (修正案) | 12 |
| Решения ВСНП (有关法律问题和重大问题的决定) | 4 |
| Надзорные регламенты (监察法规) | 3 |
| Конституция (宪法) | 1 |
| **Итого** | **1896** |

Охватываемые правовые отрасли: конституционное право, гражданское и коммерческое право, гражданский кодекс, административное право, экономическое право, социальное право, уголовное право, процессуальное право

## Формат JSON

Каждый файл соответствует одному закону, имя файла: `{заголовок}_{дата_YYYYMMDD}.json`.

**Без структуры разделов (большинство законов):**

```json
{
  "title": "中华人民共和国合同法",
  "category": "法律",
  "pub_date": "1999-03-15",
  "effective_date": "1999-10-01",
  "promulgation_info": "...",
  "issuing_org": "全国人民代表大会常务委员会",
  "doc_number": "",
  "legal_domain": "民法商法",
  "total_articles": 428,
  "chapters": [
    {
      "title": "第一章　一般规定",
      "order_index": 1,
      "global_order": 1,
      "sections": [],
      "articles": [
        {
          "title": "第一条　",
          "content": "第一条　为了保护合同当事人的合法权益...",
          "order_index": 1,
          "global_order": 2
        }
      ]
    }
  ],
  "full_text": "..."
}
```

**Со структурой разделов (Гражданский кодекс, Уголовный кодекс, ГПК и др. — 8 законов):**

```json
{
  "title": "中华人民共和国民法典",
  "parts": [
    {
      "title": "第一编　总则",
      "order_index": 1,
      "global_order": 1,
      "chapters": [...]
    }
  ]
}
```

`global_order` — порядковый номер в обходе дерева в глубину. Сортировка по этому полю даёт правильный порядок отображения.

## База данных SQLite

Запустите `python3 scripts/pipeline.py` для генерации `law_content.db` (~72МБ).

### Таблица laws

| Поле | Описание |
|------|----------|
| id | Первичный ключ |
| title | Полный заголовок |
| filename | Уникальный ключ, формат `{заголовок}_{YYYYMMDD}` |
| category | Категория документа |
| legal_domain | Правовая отрасль |
| pub_date | Дата опубликования |
| effective_date | Дата вступления в силу |
| promulgation_info | Полный текст уведомления об опубликовании |
| issuing_org | Издающий орган (Верховный суд / Верховная прокуратура / Госсовет и др.) |
| doc_number | Номер документа (например, 法释〔2000〕29号) |
| version_date | Дата версии (для различения нескольких версий) |
| is_current | Является ли текущей версией (по умолчанию 1) |

### Таблица nodes

| Поле | Описание |
|------|----------|
| id | Первичный ключ |
| law_id | Родительский закон |
| parent_id | Родительский узел (NULL для разделов верхнего уровня) |
| type | `part` / `chapter` / `section` / `article` |
| title | Заголовок раздела/главы/параграфа |
| article_number | Номер статьи, например "第一条" |
| content | Текст для отображения (заголовок для структурных узлов, текст для статей) |
| order_index | Порядок внутри родительского узла |
| global_order | Глобальный порядковый номер (обход в глубину) |

### Виртуальная таблица nodes_fts
FTS5 с `tokenize='trigram'`, индексирует `content` и `article_number`. Поддерживает поиск произвольных китайских фраз (минимум 3 символа).

### Типичные запросы

```sql
-- Вывести полное содержание закона по порядку
SELECT * FROM nodes WHERE law_id = ? ORDER BY global_order;

-- Все статьи в главе
SELECT * FROM nodes WHERE parent_id = ? AND type = 'article';

-- Полнотекстовый поиск
SELECT n.article_number, n.content, l.title AS law_title
FROM nodes_fts f
JOIN nodes n ON f.rowid = n.id
JOIN laws l ON n.law_id = l.id
WHERE nodes_fts MATCH '合同解除' AND n.type = 'article';

-- Фильтр по правовой отрасли
SELECT * FROM laws WHERE legal_domain = '民法商法' AND is_current = 1;

-- Все судебные толкования Верховного суда
SELECT title, doc_number, pub_date FROM laws
WHERE issuing_org = '最高人民法院' AND category = '司法解释'
ORDER BY pub_date DESC;
```

## Повторная генерация

```bash
pip install python-docx xlrd
python3 scripts/pipeline.py        # Полный пайплайн: docx → JSON → DB → Markdown

# Каждый этап можно запустить отдельно
cd scripts
python3 -m docx_to_json.converter  # Только перегенерировать JSON
python3 -m json_to_db.builder      # Только перегенерировать базу данных
python3 -m db_to_md.renderer       # Только перегенерировать Markdown

python3 scripts/verify_db.py       # Проверить соответствие БД и JSON (опционально)
```

После обновления исходных файлов достаточно повторно запустить `pipeline.py` — ручное вмешательство не требуется.

# 最高人民法院关于知识产权法庭若干问题的规定

**分类**：司法解释  
**法律部门**：民法商法  
**发布机关**：最高人民法院  
**公布日期**：2023-10-21  
**生效日期**：2023-11-01

> （2018年12月3日最高人民法院审判委员会第1756次会议通过；根据2023年10月16日最高人民法院审判委员会第1901次会议通过的《最高人民法院关于修改〈最高人民法院关于知识产权法庭若干问题的规定〉的决定》修正，该修正自2023年11月1日起施行）

### 正文

<a id="art-1"></a>第一条　最高人民法院设立知识产权法庭，主要审理专利等专业技术性较强的知识产权上诉案件。

<a id="art-2"></a>第二条　知识产权法庭审理下列上诉案件：

<a id="art-3"></a>第三条　审理[本规定第二条](#art-2)所称案件的下级人民法院应当按照规定及时向知识产权法庭移送纸质、电子卷宗。

<a id="art-4"></a>第四条　知识产权法庭可以要求当事人披露涉案知识产权相关权属、侵权、授权确权等关联案件情况。当事人拒不如实披露的，可以作为认定其是否遵循诚实信用原则和构成滥用权利等的考量因素。

<a id="art-5"></a>第五条　知识产权法庭可以根据案件情况到实地或者原审人民法院所在地巡回审理案件。

<a id="art-6"></a>第六条　知识产权法庭采取保全等措施，依照执行程序相关规定办理。

<a id="art-7"></a>第七条　知识产权法庭审理的案件的立案信息、合议庭组成人员、审判流程、裁判文书等依法公开。

<a id="art-8"></a>第八条　知识产权法庭法官会议由庭长、副庭长和若干资深法官组成，讨论重大、疑难、复杂案件等。

<a id="art-9"></a>第九条　知识产权法庭应当加强对有关案件审判工作的调研，及时总结裁判标准和审理规则，指导下级人民法院审判工作。

<a id="art-10"></a>第十条　对知识产权法院、中级人民法院已经发生法律效力的[本规定第二条](#art-2)第一款规定类型的第一审民事和行政案件判决、裁定、调解书，省级人民检察院向高级人民法院提出抗诉的，高级人民法院应当告知其由最高人民检察院依法向最高人民法院提出，并由知识产权法庭审理。

<a id="art-11"></a>第十一条　本规定自2019年1月1日起施行。最高人民法院此前发布的司法解释与本规定不一致的，以本规定为准。

# 中华人民共和国城市维护建设税法

**分类**：法律  
**法律部门**：经济法  
**公布日期**：2020-08-11  
**生效日期**：2021-09-01

> （2020年8月11日第十三届全国人民代表大会常务委员会第二十一次会议通过）

---

### 正文

<a id="art-1"></a>第一条　在中华人民共和国境内缴纳增值税、消费税的单位和个人，为城市维护建设税的纳税人，应当依照本法规定缴纳城市维护建设税。

<a id="art-2"></a>第二条　城市维护建设税以纳税人依法实际缴纳的增值税、消费税税额为计税依据。

<a id="art-3"></a>第三条　对进口货物或者境外单位和个人向境内销售劳务、服务、无形资产缴纳的增值税、消费税税额，不征收城市维护建设税。

<a id="art-5"></a>第五条　城市维护建设税的应纳税额按照计税依据乘以具体适用税率计算。

<a id="art-6"></a>第六条　根据国民经济和社会发展的需要，国务院对重大公共基础设施建设、特殊产业和群体以及重大突发事件应对等情形可以规定减征或者免征城市维护建设税，报全国人民代表大会常务委员会备案。

<a id="art-7"></a>第七条　城市维护建设税的纳税义务发生时间与增值税、消费税的纳税义务发生时间一致，分别与增值税、消费税同时缴纳。

<a id="art-8"></a>第八条　城市维护建设税的扣缴义务人为负有增值税、消费税扣缴义务的单位和个人，在扣缴增值税、消费税的同时扣缴城市维护建设税。

<a id="art-9"></a>第九条　城市维护建设税由税务机关依照本法和《中华人民共和国税收征收管理法》的规定征收管理。

<a id="art-10"></a>第十条　纳税人、税务机关及其工作人员违反本法规定的，依照《中华人民共和国税收征收管理法》和有关法律法规的规定追究法律责任。

<a id="art-11"></a>第十一条　本法自2021年9月1日起施行。1985年2月8日国务院发布的《中华人民共和国城市维护建设税暂行条例》同时废止。

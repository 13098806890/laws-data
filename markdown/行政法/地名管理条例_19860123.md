# 地名管理条例

**分类**：行政法规  
**法律部门**：行政法  
**公布日期**：1986-01-23  
**生效日期**：1986-01-23

> (1986年1月23日国务院发布　自发布之日起施行)

---

### 正文

<a id="art-1"></a>第一条　为了加强对地名的管理，适应社会主义现代化建设和国际交往的需要，制定本条例。

<a id="art-2"></a>第二条　本条例所称地名，包括：自然地理实体名称，行政区划名称，居民地名称，各专业部门使用的具有地名意义的台、站、港、场等名称。

<a id="art-3"></a>第三条　地名管理应当从我国地名的历史和现状出发，保持地名的相对稳定。必须命名和更名时，应当按照本条例规定的原则和审批权限报经批准。未经批准，任何单位和个人不得擅自决定。

<a id="art-7"></a>第七条　少数民族语地名的汉字译写，外国地名的汉字译写，应当做到规范化。译写规则，由中国地名委员会制定。

<a id="art-8"></a>第八条　中国地名的罗马字母拼写，以国家公布的“汉语拼音方案”作为统一规范。拼写细则，由中国地名委员会制定。

<a id="art-9"></a>第九条　经各级人民政府批准和审定的地名，由地名机构负责汇集出版。其中行政区划名称，民政部门可以汇集出版单行本。

<a id="art-10"></a>第十条　地名档案的管理，按照中国地名委员会和国家档案局的有关规定执行。

<a id="art-11"></a>第十一条　地方人民政府应责成有关部门在必要的地方设置地名标志。

<a id="art-12"></a>第十二条　本条例在实施中遇到的具体问题，由中国地名委员会研究答复。

<a id="art-13"></a>第十三条　本条例自发布之日起施行。

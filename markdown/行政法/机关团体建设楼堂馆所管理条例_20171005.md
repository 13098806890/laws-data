# 机关团体建设楼堂馆所管理条例

**分类**：行政法规  
**法律部门**：行政法  
**公布日期**：2017-10-05  
**生效日期**：2017-12-01

> (2017年8月18日国务院第182次常务会议通过　2017年10月5日中华人民共和国国务院令第688号公布　自2017年12月1日起施行)

---

### 第一章　总则

<a id="art-1"></a>第一条　为了严格控制机关、团体建设楼堂馆所，厉行节约、反对浪费，制定本条例。

<a id="art-2"></a>第二条　机关、团体建设楼堂馆所，适用本条例。

<a id="art-3"></a>第三条　建设办公用房应当严格履行审批程序，严格执行建设标准。未经批准，不得建设办公用房。

<a id="art-4"></a>第四条　建设办公用房应当遵循朴素、实用、安全、节能的原则。

<a id="art-5"></a>第五条　机关、团体不得建设培训中心等各类具有住宿、会议、餐饮等接待功能的场所和设施。

### 第二章　项目审批

<a id="art-6"></a>第六条　建设办公用房的，应当向负责项目审批的机关(以下简称审批机关)报送项目建议书、可行性研究报告、初步设计；购置办公用房的，不报送初步设计。

<a id="art-7"></a>第七条　办公用房项目的审批机关及其审批权限，按照国家有关规定执行。

<a id="art-8"></a>第八条　审批机关应当严格审核办公用房项目，按照建设标准核定建设内容、建设规模和投资概算。

<a id="art-9"></a>第九条　办公用房项目有下列情形之一的，审批机关不得批准：

<a id="art-10"></a>第十条　对未经批准的办公用房项目，不得办理规划、用地、施工等相关手续，不得安排预算、拨付资金。

<a id="art-11"></a>第十一条　办公用房项目应当按照审批机关核定的建设内容、建设规模和投资概算进行设计、施工。因国家政策调整、价格上涨、地质条件发生重大变化等原因确需增加投资概算的，应当经原审批机关批准。

<a id="art-12"></a>第十二条　审批机关应当完善审批工作流程，建立健全审批工作责任制和内部监督机制。

### 第三章　建设资金

<a id="art-13"></a>第十三条　办公用房项目的建设资金由预算资金安排。

<a id="art-14"></a>第十四条　办公用房项目的建设资金按照国库集中支付制度的有关规定支付。

<a id="art-15"></a>第十五条　办公用房项目竣工后，建设单位应当按照规定及时组织编报竣工财务决算，并及时办理固定资产入账手续。

### 第四章　监督检查

<a id="art-16"></a>第十六条　审批机关、财政部门、审计机关、监察机关(以下统称监督检查机关)应当按照各自的职责，加强对建设楼堂馆所活动的监督检查和绩效评价。

<a id="art-17"></a>第十七条　监督检查机关对建设楼堂馆所活动实施监督检查，有权要求建设单位以及其他相关单位提供有关文件和资料，向有关人员了解情况，进行现场核查。建设单位以及其他相关单位对监督检查应当予以配合，不得拒绝、阻碍。

<a id="art-18"></a>第十八条　建设单位应当按照有关规定加强办公用房项目档案管理，将项目审批和实施过程中的有关文件、资料存档备查。

<a id="art-23"></a>第二十三条　建设单位未按照规定将办公用房项目审批和实施过程中的有关文件、资料存档备查，或者转移、隐匿、篡改、毁弃有关文件、资料的，责令改正，对负有责任的领导人员和直接责任人员依法给予处分。

<a id="art-24"></a>第二十四条　[本条例第二十一条](#art-21)至第二十三条规定的处分，由监察机关或者其他有关机关按照管理权限实施，其他处理措施由审批机关实施。

<a id="art-25"></a>第二十五条　违反本条例规定，构成犯罪的，依法追究刑事责任。

### 第六章　附则

<a id="art-26"></a>第二十六条　本条例所称团体，是指工会、共青团、妇联等人民团体。

<a id="art-27"></a>第二十七条　财政给予经费保障的事业单位和人民团体以外的其他团体建设楼堂馆所，参照适用本条例。

<a id="art-28"></a>第二十八条　机关、人民团体、财政给予经费保障的事业单位和其他团体维修办公用房，应当严格履行审批程序，执行维修标准。禁止进行超标准装修或者配置超标准的设施。

<a id="art-29"></a>第二十九条　财政给予经费补助的事业单位和人民团体以外的其他团体建设、维修楼堂馆所的管理办法，由国务院发展改革部门会同国务院财政部门、住房城乡建设部门等有关部门以及有关机关事务管理部门按照确有必要、严格控制的原则制定。

<a id="art-30"></a>第三十条　军队单位建设、维修楼堂馆所，按照军队的有关规定执行。

<a id="art-31"></a>第三十一条　本条例自2017年12月1日起施行。国务院1988年9月22日发布施行的《楼堂馆所建设管理暂行条例》同时废止。

# 最高人民法院关于审理非法行医刑事案件具体应用法律若干问题的解释

**分类**：司法解释  
**法律部门**：刑法  
**发布机关**：最高人民法院  
**发文字号**：法释〔2008〕5号  
**公布日期**：2008-04-29  
**生效日期**：2008-05-09

> 最高人民法院《关于审理非法行医刑事案件具体应用法律若干问题的解释》已于2008年4月28日由最高人民法院审判委员会第1446次会议通过。现予公布，自2008年5月9日起施行。

---

### 正文

<a id="art-1"></a>第一条　具有下列情形之一的，应认定为[刑法第三百三十六条](../../刑法/中华人民共和国刑法_20201226.md#art-336)第一款规定的“未取得医生执业资格的人非法行医”：

<a id="art-2"></a>第二条　具有下列情形之一的，应认定为[刑法第三百三十六条](../../刑法/中华人民共和国刑法_20201226.md#art-336)第一款规定的“情节严重”：

<a id="art-3"></a>第三条　具有下列情形之一的，应认定为[刑法第三百三十六条](../../刑法/中华人民共和国刑法_20201226.md#art-336)第一款规定的“严重损害就诊人身体健康”：

<a id="art-4"></a>第四条　实施非法行医犯罪，同时构成生产、销售假药罪，生产、销售劣药罪，诈骗罪等其他犯罪的，依照刑法处罚较重的规定定罪处罚。

<a id="art-5"></a>第五条　本解释所称“轻度残疾、器官组织损伤导致一般功能障碍”、“中度以上残疾、器官组织损伤导致严重功能障碍”，参照卫生部《医疗事故分级标准（试行）》认定。

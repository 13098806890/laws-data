# 最高人民法院、最高人民检察院关于办理走私刑事案件适用法律若干问题的解释

**分类**：司法解释  
**法律部门**：刑法  
**发文字号**：法释〔2014〕10号  
**公布日期**：2014-08-12  
**生效日期**：2014-09-10

> 最高人民法院、最高人民检察院《关于办理走私刑事案件适用法律若干问题的解释》已于2014年2月24日由最高人民法院审判委员会第1608次会议、2014年6月13日由最高人民检察院第十二届检察委员会第23次会议通过，现予公布，自2014年9月10日起施行。

---

### 正文

<a id="art-1"></a>第一条　走私武器、弹药，具有下列情形之一的，可以认定为[刑法第一百五十一条](../../刑法/中华人民共和国刑法_20201226.md#art-151)第一款规定的“情节较轻”：

<a id="art-2"></a>第二条　[刑法第一百五十一条](../../刑法/中华人民共和国刑法_20201226.md#art-151)第一款规定的“武器、弹药”的种类，参照《中华人民共和国进口税则》及《中华人民共和国禁止进出境物品表》的有关规定确定。

<a id="art-3"></a>第三条　走私枪支散件，构成犯罪的，依照[刑法第一百五十一条](../../刑法/中华人民共和国刑法_20201226.md#art-151)第一款的规定，以走私武器罪定罪处罚。成套枪支散件以相应数量的枪支计，非成套枪支散件以每三十件为一套枪支散件计。

<a id="art-4"></a>第四条　走私各种弹药的弹头、弹壳，构成犯罪的，依照[刑法第一百五十一条](../../刑法/中华人民共和国刑法_20201226.md#art-151)第一款的规定，以走私弹药罪定罪处罚。具体的定罪量刑标准，按照[本解释第一条](#art-1)规定的数量标准的五倍执行。

<a id="art-5"></a>第五条　走私国家禁止或者限制进出口的仿真枪、管制刀具，构成犯罪的，依照[刑法第一百五十一条](../../刑法/中华人民共和国刑法_20201226.md#art-151)第三款的规定，以走私国家禁止进出口的货物、物品罪定罪处罚。具体的定罪量刑标准，适用[本解释第十一条](#art-11)第一款第六、七项和第二款的规定。

<a id="art-6"></a>第六条　走私伪造的货币，数额在二千元以上不满二万元，或者数量在二百张（枚）以上不满二千张（枚）的，可以认定为[刑法第一百五十一条](../../刑法/中华人民共和国刑法_20201226.md#art-151)第一款规定的“情节较轻”。

<a id="art-7"></a>第七条　[刑法第一百五十一条](../../刑法/中华人民共和国刑法_20201226.md#art-151)第一款规定的“货币”，包括正在流通的人民币和境外货币。伪造的境外货币数额，折合成人民币计算。

<a id="art-8"></a>第八条　走私国家禁止出口的三级文物二件以下的，可以认定为[刑法第一百五十一条](../../刑法/中华人民共和国刑法_20201226.md#art-151)第二款规定的“情节较轻”。

<a id="art-9"></a>第九条　走私国家一、二级保护动物未达到本解释附表中（一）规定的数量标准，或者走私珍贵动物制品数额不满二十万元的，可以认定为[刑法第一百五十一条](../../刑法/中华人民共和国刑法_20201226.md#art-151)第二款规定的“情节较轻”。

<a id="art-10"></a>第十条　[刑法第一百五十一条](../../刑法/中华人民共和国刑法_20201226.md#art-151)第二款规定的“珍贵动物”，包括列入《国家重点保护野生动物名录》中的国家一、二级保护野生动物，《濒危野生动植物种国际贸易公约》附录Ⅰ、附录Ⅱ中的野生动物，以及驯养繁殖的上述动物。

<a id="art-11"></a>第十一条　走私国家禁止进出口的货物、物品，具有下列情形之一的，依照[刑法第一百五十一条](../../刑法/中华人民共和国刑法_20201226.md#art-151)第三款的规定处五年以下有期徒刑或者拘役，并处或者单处罚金：

<a id="art-12"></a>第十二条　[刑法第一百五十一条](../../刑法/中华人民共和国刑法_20201226.md#art-151)第三款规定的“珍稀植物”，包括列入《国家重点保护野生植物名录》《国家重点保护野生药材物种名录》《国家珍贵树种名录》中的国家一、二级保护野生植物、国家重点保护的野生药材、珍贵树木，《濒危野生动植物种国际贸易公约》附录Ⅰ、附录Ⅱ中的野生植物，以及人工培育的上述植物。

<a id="art-14"></a>第十四条　走私国家禁止进口的废物或者国家限制进口的可用作原料的废物，具有下列情形之一的，应当认定为刑法第一百五十二条第二款规定的“情节严重”：

<a id="art-15"></a>第十五条　国家限制进口的可用作原料的废物的具体种类，参照国家有关部门的规定确定。

<a id="art-16"></a>第十六条　走私普通货物、物品，偷逃应缴税额在十万元以上不满五十万元的，应当认定为[刑法第一百五十三条](../../刑法/中华人民共和国刑法_20201226.md#art-153)第一款规定的“偷逃应缴税额较大”；偷逃应缴税额在五十万元以上不满二百五十万元的，应当认定为“偷逃应缴税额巨大”；偷逃应缴税额在二百五十万元以上的，应当认定为“偷逃应缴税额特别巨大”。

<a id="art-17"></a>第十七条　[刑法第一百五十三条](../../刑法/中华人民共和国刑法_20201226.md#art-153)第一款规定的“一年内曾因走私被给予二次行政处罚后又走私”中的“一年内”，以因走私第一次受到行政处罚的生效之日与“又走私”行为实施之日的时间间隔计算确定；“被给予二次行政处罚”的走私行为，包括走私普通货物、物品以及其他货物、物品；“又走私”行为仅指走私普通货物、物品。

<a id="art-18"></a>第十八条　[刑法第一百五十三条](../../刑法/中华人民共和国刑法_20201226.md#art-153)规定的“应缴税额”，包括进出口货物、物品应当缴纳的进出口关税和进口环节海关代征税的税额。应缴税额以走私行为实施时的税则、税率、汇率和完税价格计算；多次走私的，以每次走私行为实施时的税则、税率、汇率和完税价格逐票计算；走私行为实施时间不能确定的，以案发时的税则、税率、汇率和完税价格计算。

<a id="art-19"></a>第十九条　[刑法第一百五十四条](../../刑法/中华人民共和国刑法_20201226.md#art-154)规定的“保税货物”，是指经海关批准，未办理纳税手续进境，在境内储存、加工、装配后应予复运出境的货物，包括通过加工贸易、补偿贸易等方式进口的货物，以及在保税仓库、保税工厂、保税区或者免税商店内等储存、加工、寄售的货物。

<a id="art-20"></a>第二十条　直接向走私人非法收购走私进口的货物、物品，在内海、领海、界河、界湖运输、收购、贩卖国家禁止进出口的物品，或者没有合法证明，在内海、领海、界河、界湖运输、收购、贩卖国家限制进出口的货物、物品，构成犯罪的，应当按照走私货物、物品的种类，分别依照[刑法第一百五十一条](../../刑法/中华人民共和国刑法_20201226.md#art-151)、第一百五十二条、第一百五十三条、第三百四十七条、第三百五十条的规定定罪处罚。

<a id="art-21"></a>第二十一条　未经许可进出口国家限制进出口的货物、物品，构成犯罪的，应当依照[刑法第一百五十一条](../../刑法/中华人民共和国刑法_20201226.md#art-151)、第一百五十二条的规定，以走私国家禁止进出口的货物、物品罪等罪名定罪处罚；偷逃应缴税额，同时又构成走私普通货物、物品罪的，依照处罚较重的规定定罪处罚。

<a id="art-22"></a>第二十二条　在走私的货物、物品中藏匿[刑法第一百五十一条](../../刑法/中华人民共和国刑法_20201226.md#art-151)、第一百五十二条、第三百四十七条、第三百五十条规定的货物、物品，构成犯罪的，以实际走私的货物、物品定罪处罚；构成数罪的，实行数罪并罚。

<a id="art-24"></a>第二十四条　单位犯[刑法第一百五十一条](../../刑法/中华人民共和国刑法_20201226.md#art-151)、第一百五十二条规定之罪，依照本解释规定的标准定罪处罚。

<a id="art-25"></a>第二十五条　本解释发布实施后，《最高人民法院关于审理走私刑事案件具体应用法律若干问题的解释》（法释〔2000〕30号）、《最高人民法院关于审理走私刑事案件具体应用法律若干问题的解释（二）》（法释〔2006〕9号）同时废止。之前发布的司法解释与本解释不一致的，以本解释为准。

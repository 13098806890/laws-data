# 最高人民法院、最高人民检察院关于办理非法采供血液等刑事案件具体应用法律若干问题的解释

**分类**：司法解释  
**法律部门**：刑法  
**发文字号**：法释〔2008〕12号  
**公布日期**：2008-09-22  
**生效日期**：2008-09-23

> 最高人民法院、最高人民检察院《关于办理非法采供血液等刑事案件具体应用法律若干问题的解释》已于2008年2月18日由最高人民法院审判委员会第1444次会议、2008年5月8日由最高人民检察院第十一届检察委员会第1次会议通过，现予公布，自2008年9月23日起施行。

---

### 正文

<a id="art-1"></a>第一条　对未经国家主管部门批准或者超过批准的业务范围，采集、供应血液或者制作、供应血液制品的，应认定为刑法第三百三十四条第一款规定的“非法采集、供应血液或者制作、供应血液制品”。

<a id="art-2"></a>第二条　对非法采集、供应血液或者制作、供应血液制品，具有下列情形之一的，应认定为刑法第三百三十四条第一款规定的“不符合国家规定的标准，足以危害人体健康”，处五年以下有期徒刑或者拘役，并处罚金：

<a id="art-3"></a>第三条　对非法采集、供应血液或者制作、供应血液制品，具有下列情形之一的，应认定为刑法第三百三十四条第一款规定的“对人体健康造成严重危害”，处五年以上十年以下有期徒刑，并处罚金：

<a id="art-4"></a>第四条　对非法采集、供应血液或者制作、供应血液制品，具有下列情形之一的，应认定为刑法第三百三十四条第一款规定的“造成特别严重后果”，处十年以上有期徒刑或者无期徒刑，并处罚金或者没收财产：

<a id="art-5"></a>第五条　对经国家主管部门批准采集、供应血液或者制作、供应血液制品的部门，具有下列情形之一的，应认定为刑法第三百三十四条第二款规定的“不依照规定进行检测或者违背其他操作规定”：

<a id="art-6"></a>第六条　对经国家主管部门批准采集、供应血液或者制作、供应血液制品的部门，不依照规定进行检测或者违背其他操作规定，具有下列情形之一的，应认定为刑法第三百三十四条第二款规定的“造成危害他人身体健康后果”，对单位判处罚金，并对其直接负责的主管人员和其他直接责任人员，处五年以下有期徒刑或者拘役：

<a id="art-7"></a>第七条　经国家主管部门批准的采供血机构和血液制品生产经营单位，应认定为刑法第三百三十四条第二款规定的“经国家主管部门批准采集、供应血液或者制作、供应血液制品的部门”。

<a id="art-8"></a>第八条　本解释所称“血液”，是指全血、成分血和特殊血液成分。

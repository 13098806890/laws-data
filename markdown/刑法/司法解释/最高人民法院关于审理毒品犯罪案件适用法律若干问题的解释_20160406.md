# 最高人民法院关于审理毒品犯罪案件适用法律若干问题的解释

**分类**：司法解释  
**法律部门**：刑法  
**发布机关**：最高人民法院  
**发文字号**：法释〔2016〕8号  
**公布日期**：2016-04-06  
**生效日期**：2016-04-11

> 最高人民法院《关于审理毒品犯罪案件适用法律若干问题的解释》已于2016年1月25日由最高人民法院审判委员会第1676次会议通过，现予公布，自2016年4月11日起施行。

---

### 正文

<a id="art-1"></a>第一条　走私、贩卖、运输、制造、非法持有下列毒品，应当认定为[刑法第三百四十七条](../../刑法/中华人民共和国刑法_20201226.md#art-347)第二款第一项、第三百四十八条规定的“其他毒品数量大”：

<a id="art-2"></a>第二条　走私、贩卖、运输、制造、非法持有下列毒品，应当认定为[刑法第三百四十七条](../../刑法/中华人民共和国刑法_20201226.md#art-347)第三款、第三百四十八条规定的“其他毒品数量较大”：

<a id="art-3"></a>第三条　在实施走私、贩卖、运输、制造毒品犯罪的过程中，携带枪支、弹药或者爆炸物用于掩护的，应当认定为[刑法第三百四十七条](../../刑法/中华人民共和国刑法_20201226.md#art-347)第二款第三项规定的“武装掩护走私、贩卖、运输、制造毒品”。枪支、弹药、爆炸物种类的认定，依照相关司法解释的规定执行。

<a id="art-4"></a>第四条　走私、贩卖、运输、制造毒品，具有下列情形之一的，应当认定为[刑法第三百四十七条](../../刑法/中华人民共和国刑法_20201226.md#art-347)第四款规定的“情节严重”：

<a id="art-5"></a>第五条　非法持有毒品达到[刑法第三百四十八条](../../刑法/中华人民共和国刑法_20201226.md#art-348)或者[本解释第二条](#art-2)规定的“数量较大”标准，且具有下列情形之一的，应当认定为[刑法第三百四十八条](../../刑法/中华人民共和国刑法_20201226.md#art-348)规定的“情节严重”：

<a id="art-6"></a>第六条　包庇走私、贩卖、运输、制造毒品的犯罪分子，具有下列情形之一的，应当认定为[刑法第三百四十九条](../../刑法/中华人民共和国刑法_20201226.md#art-349)第一款规定的“情节严重”：

<a id="art-7"></a>第七条　违反国家规定，非法生产、买卖、运输制毒物品、走私制毒物品，达到下列数量标准的，应当认定为[刑法第三百五十条](../../刑法/中华人民共和国刑法_20201226.md#art-350)第一款规定的“情节较重”：

<a id="art-8"></a>第八条　违反国家规定，非法生产、买卖、运输制毒物品、走私制毒物品，具有下列情形之一的，应当认定为[刑法第三百五十条](../../刑法/中华人民共和国刑法_20201226.md#art-350)第一款规定的“情节严重”：

<a id="art-9"></a>第九条　非法种植毒品原植物，具有下列情形之一的，应当认定为[刑法第三百五十一条](../../刑法/中华人民共和国刑法_20201226.md#art-351)第一款第一项规定的“数量较大”：

<a id="art-10"></a>第十条　非法买卖、运输、携带、持有未经灭活的毒品原植物种子或者幼苗，具有下列情形之一的，应当认定为[刑法第三百五十二条](../../刑法/中华人民共和国刑法_20201226.md#art-352)规定的“数量较大”：

<a id="art-11"></a>第十一条　引诱、教唆、欺骗他人吸食、注射毒品，具有下列情形之一的，应当认定为[刑法第三百五十三条](../../刑法/中华人民共和国刑法_20201226.md#art-353)第一款规定的“情节严重”：

<a id="art-12"></a>第十二条　容留他人吸食、注射毒品，具有下列情形之一的，应当依照[刑法第三百五十四条](../../刑法/中华人民共和国刑法_20201226.md#art-354)的规定，以容留他人吸毒罪定罪处罚：

<a id="art-13"></a>第十三条　依法从事生产、运输、管理、使用国家管制的麻醉药品、精神药品的人员，违反国家规定，向吸食、注射毒品的人提供国家规定管制的能够使人形成瘾癖的麻醉药品、精神药品，具有下列情形之一的，应当依照[刑法第三百五十五条](../../刑法/中华人民共和国刑法_20201226.md#art-355)第一款的规定，以非法提供麻醉药品、精神药品罪定罪处罚：

<a id="art-14"></a>第十四条　利用信息网络，设立用于实施传授制造毒品、非法生产制毒物品的方法，贩卖毒品，非法买卖制毒物品或者组织他人吸食、注射毒品等违法犯罪活动的网站、通讯群组，或者发布实施前述违法犯罪活动的信息，情节严重的，应当依照[刑法第二百八十七条](../../刑法/中华人民共和国刑法_20201226.md#art-287)之一的规定，以非法利用信息网络罪定罪处罚。

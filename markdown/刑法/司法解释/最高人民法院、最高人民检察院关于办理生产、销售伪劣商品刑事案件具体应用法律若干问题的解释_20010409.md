# 最高人民法院、最高人民检察院关于办理生产、销售伪劣商品刑事案件具体应用法律若干问题的解释

**分类**：司法解释  
**法律部门**：刑法  
**发文字号**：法释〔2001〕10号  
**公布日期**：2001-04-09  
**生效日期**：2001-04-10

> （2001年4月5日最高人民法院审判委员会第1168次会议、2001年3月30日最高人民检察院第九届检察委员会第84次会议通过　2001年4月9日最高人民法院、最高人民检察院公告公布　自2001年4月10日起施行）

### 正文

<a id="art-1"></a>第一条　[刑法第一百四十条](../../刑法/中华人民共和国刑法_20201226.md#art-140)规定的“在产品中掺杂、掺假”，是指在产品中掺入杂质或者异物，致使产品质量不符合国家法律、法规或者产品明示质量标准规定的质量要求，降低、失去应有使用性能的行为。

<a id="art-2"></a>第二条　[刑法第一百四十条](../../刑法/中华人民共和国刑法_20201226.md#art-140)、第一百四十九条规定的“销售金额”，是指生产者、销售者出售伪劣产品后所得和应得的全部违法收入。

<a id="art-3"></a>第三条　经省级以上药品监督管理部门设置或者确定的药品检验机构鉴定，生产、销售的假药具有下列情形之一的，应认定为刑法第一百四十一条规定的“足以严重危害人体健康”：

<a id="art-4"></a>第四条　经省级以上卫生行政部门确定的机构鉴定，食品中含有可能导致严重食物中毒事故或者其他严重食源性疾患的超标准的有害细菌或者其他污染物的，应认定为刑法第一百四十三条规定的“足以造成严重食物中毒事故或者其他严重食源性疾患”。

<a id="art-5"></a>第五条　生产、销售的有毒、有害食品被食用后，造成轻伤、重伤或者其他严重后果的，应认定为刑法第一百四十四条规定的“对人体健康造成严重危害”。

<a id="art-6"></a>第六条　生产、销售不符合标准的医疗器械、医用卫生材料，致人轻伤或者其他严重后果的，应认定为刑法第一百四十五条规定的“对人体健康造成严重危害”。

<a id="art-7"></a>第七条　[刑法第一百四十七条](../../刑法/中华人民共和国刑法_20201226.md#art-147)规定的生产、销售伪劣农药、兽药、化肥、种子罪中“使生产遭受较大损失”，一般以2万元为起点；“重大损失”，一般以10万元为起点；“特别重大损失”，一般以50万元为起点。

<a id="art-8"></a>第八条　国家机关工作人员徇私舞弊，对生产、销售伪劣商品犯罪不履行法律规定的查处职责，具有下列情形之一的，属于刑法第四百一十四条规定的“情节严重”：

<a id="art-9"></a>第九条　知道或者应当知道他人实施生产、销售伪劣商品犯罪，而为其提供贷款、资金、账号、发票、证明、许可证件，或者提供生产、经营场所或者运输、仓储、保管、邮寄等便利条件，或者提供制假生产技术的，以生产、销售伪劣商品犯罪的共犯论处。

<a id="art-10"></a>第十条　实施生产、销售伪劣商品犯罪，同时构成侵犯知识产权、非法经营等其他犯罪的，依照处罚较重的规定定罪处罚。

<a id="art-11"></a>第十一条　实施[刑法第一百四十条](../../刑法/中华人民共和国刑法_20201226.md#art-140)至第一百四十八条规定的犯罪，又以暴力、威胁方法抗拒查处，构成其他犯罪的，依照数罪并罚的规定处罚。

<a id="art-12"></a>第十二条　国家机关工作人员参与生产、销售伪劣商品犯罪的，从重处罚。

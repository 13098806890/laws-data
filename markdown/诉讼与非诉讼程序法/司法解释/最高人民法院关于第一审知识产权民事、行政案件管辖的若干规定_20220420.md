# 最高人民法院关于第一审知识产权民事、行政案件管辖的若干规定

**分类**：司法解释  
**法律部门**：诉讼与非诉讼程序法  
**发布机关**：最高人民法院  
**发文字号**：法释〔2022〕13号  
**公布日期**：2022-04-20  
**生效日期**：2022-05-01

> （2021年12月27日最高人民法院审判委员会第1858次会议通过，自2022年5月1日起施行）

---

### 正文

<a id="art-1"></a>第一条　发明专利、实用新型专利、植物新品种、集成电路布图设计、技术秘密、计算机软件的权属、侵权纠纷以及垄断纠纷第一审民事、行政案件由知识产权法院，省、自治区、直辖市人民政府所在地的中级人民法院和最高人民法院确定的中级人民法院管辖。

<a id="art-2"></a>第二条　外观设计专利的权属、侵权纠纷以及涉驰名商标认定第一审民事、行政案件由知识产权法院和中级人民法院管辖；经最高人民法院批准，也可以由基层人民法院管辖，但外观设计专利行政案件除外。

<a id="art-3"></a>第三条　[本规定第一条](#art-1)、第二条规定之外的第一审知识产权民事、行政案件，由最高人民法院确定的基层人民法院管辖。

<a id="art-4"></a>第四条　对新类型、疑难复杂或者具有法律适用指导意义等知识产权民事、行政案件，上级人民法院可以依照诉讼法有关规定，根据下级人民法院报请或者自行决定提级审理。

<a id="art-5"></a>第五条　依照本规定需要最高人民法院确定管辖或者调整管辖的诉讼标的额标准、区域范围的，应当层报最高人民法院批准。

<a id="art-6"></a>第六条　本规定自2022年5月1日起施行。

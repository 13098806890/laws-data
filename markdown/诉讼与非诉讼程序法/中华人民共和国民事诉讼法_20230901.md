## 第一编　总则

### 第一章　任务、适用范围和基本原则

<a id="art-1"></a>第一条　中华人民共和国民事诉讼法以宪法为根据，结合我国民事审判工作的经验和实际情况制定。

<a id="art-2"></a>第二条　中华人民共和国民事诉讼法的任务，是保护当事人行使诉讼权利，保证人民法院查明事实，分清是非，正确适用法律，及时审理民事案件，确认民事权利义务关系，制裁民事违法行为，保护当事人的合法权益，教育公民自觉遵守法律，维护社会秩序、经济秩序，保障社会主义建设事业顺利进行。

<a id="art-3"></a>第三条　人民法院受理公民之间、法人之间、其他组织之间以及他们相互之间因财产关系和人身关系提起的民事诉讼，适用本法的规定。

<a id="art-4"></a>第四条　凡在中华人民共和国领域内进行民事诉讼，必须遵守本法。

<a id="art-5"></a>第五条　外国人、无国籍人、外国企业和组织在人民法院起诉、应诉，同中华人民共和国公民、法人和其他组织有同等的诉讼权利义务。

<a id="art-6"></a>第六条　民事案件的审判权由人民法院行使。

<a id="art-7"></a>第七条　人民法院审理民事案件，必须以事实为根据，以法律为准绳。

<a id="art-8"></a>第八条　民事诉讼当事人有平等的诉讼权利。人民法院审理民事案件，应当保障和便利当事人行使诉讼权利，对当事人在适用法律上一律平等。

<a id="art-9"></a>第九条　人民法院审理民事案件，应当根据自愿和合法的原则进行调解；调解不成的，应当及时判决。

<a id="art-10"></a>第十条　人民法院审理民事案件，依照法律规定实行合议、回避、公开审判和两审终审制度。

<a id="art-11"></a>第十一条　各民族公民都有用本民族语言、文字进行民事诉讼的权利。

<a id="art-12"></a>第十二条　人民法院审理民事案件时，当事人有权进行辩论。

<a id="art-13"></a>第十三条　民事诉讼应当遵循诚信原则。

<a id="art-14"></a>第十四条　人民检察院有权对民事诉讼实行法律监督。

<a id="art-15"></a>第十五条　机关、社会团体、企业事业单位对损害国家、集体或者个人民事权益的行为，可以支持受损害的单位或者个人向人民法院起诉。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于审理环境民事公益诉讼案件适用法律若干问题的解释_20201229.md#art-11" title="被《最高人民法院关于审理环境民事公益诉讼案件适用法律若干问题的解释》第11条引用">[1]</a></sup>

<a id="art-16"></a>第十六条　经当事人同意，民事诉讼活动可以通过信息网络平台在线进行。

<a id="art-17"></a>第十七条　民族自治地方的人民代表大会根据宪法和本法的原则，结合当地民族的具体情况，可以制定变通或者补充的规定。自治区的规定，报全国人民代表大会常务委员会批准。自治州、自治县的规定，报省或者自治区的人民代表大会常务委员会批准，并报全国人民代表大会常务委员会备案。

### 第三章　审判组织

<a id="art-40"></a>第四十条　人民法院审理第一审民事案件，由审判员、人民陪审员共同组成合议庭或者由审判员组成合议庭。合议庭的成员人数，必须是单数。

<a id="art-41"></a>第四十一条　人民法院审理第二审民事案件，由审判员组成合议庭。合议庭的成员人数，必须是单数。

<a id="art-42"></a>第四十二条　人民法院审理下列民事案件，不得由审判员一人独任审理：

<a id="art-43"></a>第四十三条　人民法院在审理过程中，发现案件不宜由审判员一人独任审理的，应当裁定转由合议庭审理。

<a id="art-44"></a>第四十四条　合议庭的审判长由院长或者庭长指定审判员一人担任；院长或者庭长参加审判的，由院长或者庭长担任。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/人民检察院民事诉讼监督规则_20210626.md#art-12" title="被《人民检察院民事诉讼监督规则》第12条引用">[1]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/人民检察院民事诉讼监督规则_20210626.md#art-14" title="被《人民检察院民事诉讼监督规则》第14条引用">[2]</a></sup>

<a id="art-46"></a>第四十六条　审判人员应当依法秉公办案。

<a id="art-47"></a>第四十七条　审判人员有下列情形之一的，应当自行回避，当事人有权用口头或者书面方式申请他们回避：&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-48" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第48条引用">[1]</a></sup>

<a id="art-50"></a>第五十条　人民法院对当事人提出的回避申请，应当在申请提出的三日内，以口头或者书面形式作出决定。申请人对决定不服的，可以在接到决定时申请复议一次。复议期间，被申请回避的人员，不停止参与本案的工作。人民法院对复议申请，应当在三日内作出复议决定，并通知复议申请人。

### 第五章　诉讼参加人

#### 第一节　当事人

<a id="art-51"></a>第五十一条　公民、法人和其他组织可以作为民事诉讼的当事人。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-52" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第52条引用">[1]</a></sup>

<a id="art-52"></a>第五十二条　当事人有权委托代理人，提出回避申请，收集、提供证据，进行辩论，请求调解，提起上诉，申请执行。

<a id="art-53"></a>第五十三条　双方当事人可以自行和解。

<a id="art-54"></a>第五十四条　原告可以放弃或者变更诉讼请求。被告可以承认或者反驳诉讼请求，有权提起反诉。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于证券纠纷代表人诉讼若干问题的规定_20200730.md#art-32" title="被《最高人民法院关于证券纠纷代表人诉讼若干问题的规定》第32条引用">[1]</a></sup>

<a id="art-55"></a>第五十五条　当事人一方或者双方为二人以上，其诉讼标的是共同的，或者诉讼标的是同一种类、人民法院认为可以合并审理并经当事人同意的，为共同诉讼。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院、最高人民检察院关于检察公益诉讼案件适用法律若干问题的解释_20201229.md#art-15" title="被《最高人民法院、最高人民检察院关于检察公益诉讼案件适用法律若干问题的解释》第15条引用">[1]</a></sup>&thinsp;<sup><a href="../民法商法/司法解释/最高人民法院关于审理使用人脸识别技术处理个人信息相关民事案件适用法律若干问题的规定_20210727.md#art-14" title="被《最高人民法院关于审理使用人脸识别技术处理个人信息相关民事案件适用法律若干问题的规定》第14条引用">[2]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于审理环境民事公益诉讼案件适用法律若干问题的解释_20201229.md#art-1" title="被《最高人民法院关于审理环境民事公益诉讼案件适用法律若干问题的解释》第1条引用">[3]</a></sup>

<a id="art-56"></a>第五十六条　当事人一方人数众多的共同诉讼，可以由当事人推选代表人进行诉讼。代表人的诉讼行为对其所代表的当事人发生效力，但代表人变更、放弃诉讼请求或者承认对方当事人的诉讼请求，进行和解，必须经被代表的当事人同意。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-75" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第75条引用">[1]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-76" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第76条引用">[2]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-78" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第78条引用">[3]</a></sup>

<a id="art-57"></a>第五十七条　诉讼标的是同一种类、当事人一方人数众多在起诉时人数尚未确定的，人民法院可以发出公告，说明案件情况和诉讼请求，通知权利人在一定期间向人民法院登记。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-77" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第77条引用">[1]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-79" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第79条引用">[2]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-80" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第80条引用">[3]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-194" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第194条引用">[4]</a></sup>

<a id="art-58"></a>第五十八条　对污染环境、侵害众多消费者合法权益等损害社会公共利益的行为，法律规定的机关和有关组织可以向人民法院提起诉讼。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-282" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第282条引用">[1]</a></sup>

<a id="art-59"></a>第五十九条　对当事人双方的诉讼标的，第三人认为有独立请求权的，有权提起诉讼。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于知识产权民事诉讼证据的若干规定_20201116.md#art-10" title="被《最高人民法院关于知识产权民事诉讼证据的若干规定》第10条引用">[1]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-81" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第81条引用">[2]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-127" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第127条引用">[3]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-293" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第293条引用">[4]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-294" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第294条引用">[5]</a></sup>

#### 第二节　诉讼代理人

<a id="art-60"></a>第六十条　无诉讼行为能力人由他的监护人作为法定代理人代为诉讼。法定代理人之间互相推诿代理责任的，由人民法院指定其中一人代为诉讼。

<a id="art-61"></a>第六十一条　当事人、法定代理人可以委托一至二人作为诉讼代理人。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-85" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第85条引用">[1]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-86" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第86条引用">[2]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-87" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第87条引用">[3]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-351" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第351条引用">[4]</a></sup>

<a id="art-62"></a>第六十二条　委托他人代为诉讼，必须向人民法院提交由委托人签名或者盖章的授权委托书。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-88" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第88条引用">[1]</a></sup>

<a id="art-63"></a>第六十三条　诉讼代理人的权限如果变更或者解除，当事人应当书面告知人民法院，并由人民法院通知对方当事人。

<a id="art-64"></a>第六十四条　代理诉讼的律师和其他诉讼代理人有权调查收集证据，可以查阅本案有关材料。查阅本案有关材料的范围和办法由最高人民法院规定。&thinsp;<sup><a href="../民法商法/司法解释/最高人民法院关于审理使用人脸识别技术处理个人信息相关民事案件适用法律若干问题的规定_20210727.md#art-6" title="被《最高人民法院关于审理使用人脸识别技术处理个人信息相关民事案件适用法律若干问题的规定》第6条引用">[1]</a></sup>

<a id="art-65"></a>第六十五条　离婚案件有诉讼代理人的，本人除不能表达意思的以外，仍应出庭；确因特殊情况无法出庭的，必须向人民法院提交书面意见。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于民事诉讼证据的若干规定_20191225.md#art-52" title="被《最高人民法院关于民事诉讼证据的若干规定》第52条引用">[1]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于知识产权民事诉讼证据的若干规定_20201116.md#art-2" title="被《最高人民法院关于知识产权民事诉讼证据的若干规定》第2条引用">[2]</a></sup>

### 第六章　证据

<a id="art-66"></a>第六十六条　证据包括：

<a id="art-67"></a>第六十七条　当事人对自己提出的主张，有责任提供证据。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-94" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第94条引用">[1]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-96" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第96条引用">[2]</a></sup>

<a id="art-68"></a>第六十八条　当事人对自己提出的主张应当及时提供证据。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-102" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第102条引用">[1]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-231" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第231条引用">[2]</a></sup>

<a id="art-69"></a>第六十九条　人民法院收到当事人提交的证据材料，应当出具收据，写明证据名称、页数、份数、原件或者复印件以及收到时间等，并由经办人员签名或者盖章。

<a id="art-70"></a>第七十条　人民法院有权向有关单位和个人调查取证，有关单位和个人不得拒绝。

<a id="art-71"></a>第七十一条　证据应当在法庭上出示，并由当事人互相质证。对涉及国家秘密、商业秘密和个人隐私的证据应当保密，需要在法庭出示的，不得在公开开庭时出示。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-220" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第220条引用">[1]</a></sup>

<a id="art-72"></a>第七十二条　经过法定程序公证证明的法律事实和文书，人民法院应当作为认定事实的根据，但有相反证据足以推翻公证证明的除外。

<a id="art-73"></a>第七十三条　书证应当提交原件。物证应当提交原物。提交原件或者原物确有困难的，可以提交复制品、照片、副本、节录本。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-111" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第111条引用">[1]</a></sup>

<a id="art-74"></a>第七十四条　人民法院对视听资料，应当辨别真伪，并结合本案的其他证据，审查确定能否作为认定事实的根据。

<a id="art-75"></a>第七十五条　凡是知道案件情况的单位和个人，都有义务出庭作证。有关单位的负责人应当支持证人作证。

<a id="art-76"></a>第七十六条　经人民法院通知，证人应当出庭作证。有下列情形之一的，经人民法院许可，可以通过书面证言、视听传输技术或者视听资料等方式作证：&thinsp;<sup><a href="../民法商法/司法解释/最高人民法院关于审理企业破产案件若干问题的规定_20020730.md#art-24" title="被《最高人民法院关于审理企业破产案件若干问题的规定》第24条引用">[1]</a></sup>

<a id="art-77"></a>第七十七条　证人因履行出庭作证义务而支出的交通、住宿、就餐等必要费用以及误工损失，由败诉一方当事人负担。当事人申请证人作证的，由该当事人先行垫付；当事人没有申请，人民法院通知证人作证的，由人民法院先行垫付。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-118" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第118条引用">[1]</a></sup>

<a id="art-78"></a>第七十八条　人民法院对当事人的陈述，应当结合本案的其他证据，审查确定能否作为认定事实的根据。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于民事诉讼证据的若干规定_20191225.md#art-79" title="被《最高人民法院关于民事诉讼证据的若干规定》第79条引用">[1]</a></sup>

<a id="art-79"></a>第七十九条　当事人可以就查明事实的专门性问题向人民法院申请鉴定。当事人申请鉴定的，由双方当事人协商确定具备资格的鉴定人；协商不成的，由人民法院指定。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于民事诉讼证据的若干规定_20191225.md#art-83" title="被《最高人民法院关于民事诉讼证据的若干规定》第83条引用">[1]</a></sup>

<a id="art-80"></a>第八十条　鉴定人有权了解进行鉴定所需要的案件材料，必要时可以询问当事人、证人。

<a id="art-81"></a>第八十一条　当事人对鉴定意见有异议或者人民法院认为鉴定人有必要出庭的，鉴定人应当出庭作证。经人民法院通知，鉴定人拒不出庭作证的，鉴定意见不得作为认定事实的根据；支付鉴定费用的当事人可以要求返还鉴定费用。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于审理消费民事公益诉讼案件适用法律若干问题的解释_20201229.md#art-8" title="被《最高人民法院关于审理消费民事公益诉讼案件适用法律若干问题的解释》第8条引用">[1]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于民事诉讼证据的若干规定_20191225.md#art-25" title="被《最高人民法院关于民事诉讼证据的若干规定》第25条引用">[2]</a></sup>

<a id="art-82"></a>第八十二条　当事人可以申请人民法院通知有专门知识的人出庭，就鉴定人作出的鉴定意见或者专业问题提出意见。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-122" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第122条引用">[1]</a></sup>

<a id="art-83"></a>第八十三条　勘验物证或者现场，勘验人必须出示人民法院的证件，并邀请当地基层组织或者当事人所在单位派人参加。当事人或者当事人的成年家属应当到场，拒不到场的，不影响勘验的进行。

<a id="art-84"></a>第八十四条　在证据可能灭失或者以后难以取得的情况下，当事人可以在诉讼过程中向人民法院申请保全证据，人民法院也可以主动采取保全措施。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-98" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第98条引用">[1]</a></sup>

### 第七章　期间、送达

#### 第一节　期间

<a id="art-85"></a>第八十五条　期间包括法定期间和人民法院指定的期间。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-125" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第125条引用">[1]</a></sup>

<a id="art-86"></a>第八十六条　当事人因不可抗拒的事由或者其他正当理由耽误期限的，在障碍消除后的十日内，可以申请顺延期限，是否准许，由人民法院决定。&thinsp;<sup><a href="../民法商法/司法解释/最高人民法院关于适用简易程序审理民事案件的若干规定_20201229.md#art-11" title="被《最高人民法院关于适用简易程序审理民事案件的若干规定》第11条引用">[1]</a></sup>

#### 第二节　送达

<a id="art-87"></a>第八十七条　送达诉讼文书必须有送达回证，由受送达人在送达回证上记明收到日期，签名或者盖章。

<a id="art-88"></a>第八十八条　送达诉讼文书，应当直接送交受送达人。受送达人是公民的，本人不在交他的同住成年家属签收；受送达人是法人或者其他组织的，应当由法人的法定代表人、其他组织的主要负责人或者该法人、组织负责收件的人签收；受送达人有诉讼代理人的，可以送交其代理人签收；受送达人已向人民法院指定代收人的，送交代收人签收。

<a id="art-89"></a>第八十九条　受送达人或者他的同住成年家属拒绝接收诉讼文书的，送达人可以邀请有关基层组织或者所在单位的代表到场，说明情况，在送达回证上记明拒收事由和日期，由送达人、见证人签名或者盖章，把诉讼文书留在受送达人的住所；也可以把诉讼文书留在受送达人的住所，并采用拍照、录像等方式记录送达过程，即视为送达。

<a id="art-90"></a>第九十条　经受送达人同意，人民法院可以采用能够确认其收悉的电子方式送达诉讼文书。通过电子方式送达的判决书、裁定书、调解书，受送达人提出需要纸质文书的，人民法院应当提供。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-261" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第261条引用">[1]</a></sup>

<a id="art-91"></a>第九十一条　直接送达诉讼文书有困难的，可以委托其他人民法院代为送达，或者邮寄送达。邮寄送达的，以回执上注明的收件日期为送达日期。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-134" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第134条引用">[1]</a></sup>

<a id="art-92"></a>第九十二条　受送达人是军人的，通过其所在部队团以上单位的政治机关转交。

<a id="art-93"></a>第九十三条　受送达人被监禁的，通过其所在监所转交。

<a id="art-94"></a>第九十四条　代为转交的机关、单位收到诉讼文书后，必须立即交受送达人签收，以在送达回证上的签收日期，为送达日期。

<a id="art-95"></a>第九十五条　受送达人下落不明，或者用本节规定的其他方式无法送达的，公告送达。自发出公告之日起，经过三十日，即视为送达。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于人民法院民事调解工作若干问题的规定_20201229.md#art-1" title="被《最高人民法院关于人民法院民事调解工作若干问题的规定》第1条引用">[1]</a></sup>

### 第八章　调解

<a id="art-96"></a>第九十六条　人民法院审理民事案件，根据当事人自愿的原则，在事实清楚的基础上，分清是非，进行调解。&thinsp;<sup><a href="../民法商法/司法解释/最高人民法院关于当事人申请财产保全错误造成案外人损失应否承担赔偿责任问题的解释_20050815.md#art-1" title="被《最高人民法院关于当事人申请财产保全错误造成案外人损失应否承担赔偿责任问题的解释》第1条引用">[1]</a></sup>

<a id="art-97"></a>第九十七条　人民法院进行调解，可以由审判员一人主持，也可以由合议庭主持，并尽可能就地进行。

<a id="art-98"></a>第九十八条　人民法院进行调解，可以邀请有关单位和个人协助。被邀请的单位和个人，应当协助人民法院进行调解。

<a id="art-99"></a>第九十九条　调解达成协议，必须双方自愿，不得强迫。调解协议的内容不得违反法律规定。

<a id="art-100"></a>第一百条　调解达成协议，人民法院应当制作调解书。调解书应当写明诉讼请求、案件的事实和调解结果。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于人民法院办理财产保全案件若干问题的规定_20201229.md#art-5" title="被《最高人民法院关于人民法院办理财产保全案件若干问题的规定》第5条引用">[1]</a></sup>&thinsp;<sup><a href="../民法商法/司法解释/最高人民法院关于审查知识产权纠纷行为保全案件适用法律若干问题的规定_20181212.md#art-2" title="被《最高人民法院关于审查知识产权纠纷行为保全案件适用法律若干问题的规定》第2条引用">[2]</a></sup>&thinsp;<sup><a href="../民法商法/司法解释/最高人民法院关于审查知识产权纠纷行为保全案件适用法律若干问题的规定_20181212.md#art-6" title="被《最高人民法院关于审查知识产权纠纷行为保全案件适用法律若干问题的规定》第6条引用">[3]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于民事执行中变更、追加当事人若干问题的规定_20201229.md#art-29" title="被《最高人民法院关于民事执行中变更、追加当事人若干问题的规定》第29条引用">[4]</a></sup>

<a id="art-101"></a>第一百零一条　下列案件调解达成协议，人民法院可以不制作调解书：&thinsp;<sup><a href="../民法商法/司法解释/最高人民法院关于审查知识产权纠纷行为保全案件适用法律若干问题的规定_20181212.md#art-10" title="被《最高人民法院关于审查知识产权纠纷行为保全案件适用法律若干问题的规定》第10条引用">[1]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-151" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第151条引用">[2]</a></sup>

<a id="art-102"></a>第一百零二条　调解未达成协议或者调解书送达前一方反悔的，人民法院应当及时判决。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于限制被执行人高消费的若干规定_20100701.md#art-11" title="被《最高人民法院关于限制被执行人高消费的若干规定》第11条引用">[1]</a></sup>

### 第九章　保全和先予执行

<a id="art-103"></a>第一百零三条　人民法院对于可能因当事人一方的行为或者其他原因，使判决难以执行或者造成当事人其他损害的案件，根据对方当事人的申请，可以裁定对其财产进行保全、责令其作出一定行为或者禁止其作出一定行为；当事人没有提出申请的，人民法院在必要时也可以裁定采取保全措施。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-152" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第152条引用">[1]</a></sup>

<a id="art-104"></a>第一百零四条　利害关系人因情况紧急，不立即申请保全将会使其合法权益受到难以弥补的损害的，可以在提起诉讼或者申请仲裁前向被保全财产所在地、被申请人住所地或者对案件有管辖权的人民法院申请采取保全措施。申请人应当提供担保，不提供担保的，裁定驳回申请。

<a id="art-105"></a>第一百零五条　保全限于请求的范围，或者与本案有关的财物。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于因申请诉中财产保全损害责任纠纷管辖问题的批复_20170801.md#art-1" title="被《最高人民法院关于因申请诉中财产保全损害责任纠纷管辖问题的批复》第1条引用">[1]</a></sup>&thinsp;<sup><a href="../民法商法/司法解释/最高人民法院关于审查知识产权纠纷行为保全案件适用法律若干问题的规定_20181212.md#art-16" title="被《最高人民法院关于审查知识产权纠纷行为保全案件适用法律若干问题的规定》第16条引用">[2]</a></sup>&thinsp;<sup><a href="../民法商法/司法解释/最高人民法院关于审查知识产权纠纷行为保全案件适用法律若干问题的规定_20181212.md#art-18" title="被《最高人民法院关于审查知识产权纠纷行为保全案件适用法律若干问题的规定》第18条引用">[3]</a></sup>

<a id="art-106"></a>第一百零六条　财产保全采取查封、扣押、冻结或者法律规定的其他方法。人民法院保全财产后，应当立即通知被保全财产的人。

<a id="art-107"></a>第一百零七条　财产纠纷案件，被申请人提供担保的，人民法院应当裁定解除保全。

<a id="art-108"></a>第一百零八条　申请有错误的，申请人应当赔偿被申请人因保全所遭受的损失。

<a id="art-109"></a>第一百零九条　人民法院对下列案件，根据当事人的申请，可以裁定先予执行：&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-170" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第170条引用">[1]</a></sup>

<a id="art-110"></a>第一百一十条　人民法院裁定先予执行的，应当符合下列条件：&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于民事诉讼证据的若干规定_20191225.md#art-78" title="被《最高人民法院关于民事诉讼证据的若干规定》第78条引用">[1]</a></sup>

<a id="art-111"></a>第一百一十一条　当事人对保全或者先予执行的裁定不服的，可以申请复议一次。复议期间不停止裁定的执行。&thinsp;<sup><a href="../民法商法/司法解释/最高人民法院关于审理侵害植物新品种权纠纷案件具体应用法律问题的若干规定（二）_20210705.md#art-16" title="被《最高人民法院关于审理侵害植物新品种权纠纷案件具体应用法律问题的若干规定（二）》第16条引用">[1]</a></sup>&thinsp;<sup><a href="../民法商法/司法解释/最高人民法院关于审理申请注册的药品相关的专利权纠纷民事案件适用法律若干问题的规定_20210704.md#art-8" title="被《最高人民法院关于审理申请注册的药品相关的专利权纠纷民事案件适用法律若干问题的规定》第8条引用">[2]</a></sup>&thinsp;<sup><a href="../民法商法/司法解释/最高人民法院关于审理申请注册的药品相关的专利权纠纷民事案件适用法律若干问题的规定_20210704.md#art-9" title="被《最高人民法院关于审理申请注册的药品相关的专利权纠纷民事案件适用法律若干问题的规定》第9条引用">[3]</a></sup>&thinsp;<sup><a href="../民法商法/司法解释/最高人民法院关于审理票据纠纷案件若干问题的规定_20201229.md#art-38" title="被《最高人民法院关于审理票据纠纷案件若干问题的规定》第38条引用">[4]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于民事诉讼证据的若干规定_20191225.md#art-42" title="被《最高人民法院关于民事诉讼证据的若干规定》第42条引用">[5]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于知识产权民事诉讼证据的若干规定_20201116.md#art-13" title="被《最高人民法院关于知识产权民事诉讼证据的若干规定》第13条引用">[6]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于知识产权民事诉讼证据的若干规定_20201116.md#art-14" title="被《最高人民法院关于知识产权民事诉讼证据的若干规定》第14条引用">[7]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-172" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第172条引用">[8]</a></sup>&thinsp;<sup><a href="../民法典/司法解释/最高人民法院关于适用《中华人民共和国民法典》婚姻家庭编的解释（一）_20201229.md#art-61" title="被《最高人民法院关于适用《中华人民共和国民法典》婚姻家庭编的解释（一）》第61条引用">[9]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于限制被执行人高消费及有关消费的若干规定_20150720.md#art-11" title="被《最高人民法院关于限制被执行人高消费及有关消费的若干规定》第11条引用">[10]</a></sup>

### 第十章　对妨害民事诉讼的强制措施

### 第十五章　特别程序

#### 第一节　一般规定

<a id="art-184"></a>第一百八十四条　人民法院审理选民资格案件、宣告失踪或者宣告死亡案件、指定遗产管理人案件、认定公民无民事行为能力或者限制民事行为能力案件、认定财产无主案件、确认调解协议案件和实现担保物权案件，适用本章规定。本章没有规定的，适用本法和其他法律的有关规定。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于修改后的民事诉讼法施行时未结案件适用法律若干问题的规定_20121228.md#art-6" title="被《最高人民法院关于修改后的民事诉讼法施行时未结案件适用法律若干问题的规定》第6条引用">[1]</a></sup>

<a id="art-185"></a>第一百八十五条　依照本章程序审理的案件，实行一审终审。选民资格案件或者重大、疑难的案件，由审判员组成合议庭审理；其他案件由审判员一人独任审理。

<a id="art-186"></a>第一百八十六条　人民法院在依照本章程序审理案件的过程中，发现本案属于民事权益争议的，应当裁定终结特别程序，并告知利害关系人可以另行起诉。

<a id="art-187"></a>第一百八十七条　人民法院适用特别程序审理的案件，应当在立案之日起三十日内或者公告期满后三十日内审结。有特殊情况需要延长的，由本院院长批准。但审理选民资格的案件除外。

#### 第二节　选民资格案件

<a id="art-188"></a>第一百八十八条　公民不服选举委员会对选民资格的申诉所作的处理决定，可以在选举日的五日以前向选区所在地基层人民法院起诉。

<a id="art-189"></a>第一百八十九条　人民法院受理选民资格案件后，必须在选举日前审结。

#### 第三节　宣告失踪、宣告死亡案件

<a id="art-190"></a>第一百九十条　公民下落不明满二年，利害关系人申请宣告其失踪的，向下落不明人住所地基层人民法院提出。

<a id="art-191"></a>第一百九十一条　公民下落不明满四年，或者因意外事件下落不明满二年，或者因意外事件下落不明，经有关机关证明该公民不可能生存，利害关系人申请宣告其死亡的，向下落不明人住所地基层人民法院提出。

<a id="art-192"></a>第一百九十二条　人民法院受理宣告失踪、宣告死亡案件后，应当发出寻找下落不明人的公告。宣告失踪的公告期间为三个月，宣告死亡的公告期间为一年。因意外事件下落不明，经有关机关证明该公民不可能生存的，宣告死亡的公告期间为三个月。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-343" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第343条引用">[1]</a></sup>

<a id="art-193"></a>第一百九十三条　被宣告失踪、宣告死亡的公民重新出现，经本人或者利害关系人申请，人民法院应当作出新判决，撤销原判决。

#### 第四节　指定遗产管理人案件

<a id="art-194"></a>第一百九十四条　对遗产管理人的确定有争议，利害关系人申请指定遗产管理人的，向被继承人死亡时住所地或者主要遗产所在地基层人民法院提出。

<a id="art-195"></a>第一百九十五条　人民法院受理申请后，应当审查核实，并按照有利于遗产管理的原则，判决指定遗产管理人。

<a id="art-196"></a>第一百九十六条　被指定的遗产管理人死亡、终止、丧失民事行为能力或者存在其他无法继续履行遗产管理职责情形的，人民法院可以根据利害关系人或者本人的申请另行指定遗产管理人。

<a id="art-197"></a>第一百九十七条　遗产管理人违反遗产管理职责，严重侵害继承人、受遗赠人或者债权人合法权益的，人民法院可以根据利害关系人的申请，撤销其遗产管理人资格，并依法指定新的遗产管理人。

#### 第五节　认定公民无民事行为能力、限制民事行为能力案件

<a id="art-198"></a>第一百九十八条　申请认定公民无民事行为能力或者限制民事行为能力，由利害关系人或者有关组织向该公民住所地基层人民法院提出。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》审判监督程序若干问题的解释_20201229.md#art-21" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》审判监督程序若干问题的解释》第21条引用">[1]</a></sup>

<a id="art-199"></a>第一百九十九条　人民法院受理申请后，必要时应当对被请求认定为无民事行为能力或者限制民事行为能力的公民进行鉴定。申请人已提供鉴定意见的，应当对鉴定意见进行审查。

<a id="art-200"></a>第二百条　人民法院审理认定公民无民事行为能力或者限制民事行为能力的案件，应当由该公民的近亲属为代理人，但申请人除外。近亲属互相推诿的，由人民法院指定其中一人为代理人。该公民健康情况许可的，还应当询问本人的意见。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/人民检察院民事诉讼监督规则_20210626.md#art-74" title="被《人民检察院民事诉讼监督规则》第74条引用">[1]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/人民检察院民事诉讼监督规则_20210626.md#art-76" title="被《人民检察院民事诉讼监督规则》第76条引用">[2]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/人民检察院民事诉讼监督规则_20210626.md#art-77" title="被《人民检察院民事诉讼监督规则》第77条引用">[3]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/人民检察院民事诉讼监督规则_20210626.md#art-78" title="被《人民检察院民事诉讼监督规则》第78条引用">[4]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/人民检察院民事诉讼监督规则_20210626.md#art-79" title="被《人民检察院民事诉讼监督规则》第79条引用">[5]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/人民检察院民事诉讼监督规则_20210626.md#art-80" title="被《人民检察院民事诉讼监督规则》第80条引用">[6]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/人民检察院民事诉讼监督规则_20210626.md#art-90" title="被《人民检察院民事诉讼监督规则》第90条引用">[7]</a></sup>&thinsp;<sup><a href="../民法商法/司法解释/最高人民法院关于民事审判监督程序严格依法适用指令再审和发回重审若干问题的规定_20150216.md#art-1" title="被《最高人民法院关于民事审判监督程序严格依法适用指令再审和发回重审若干问题的规定》第1条引用">[8]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》审判监督程序若干问题的解释_20201229.md#art-1" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》审判监督程序若干问题的解释》第1条引用">[9]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》审判监督程序若干问题的解释_20201229.md#art-9" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》审判监督程序若干问题的解释》第9条引用">[10]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》审判监督程序若干问题的解释_20201229.md#art-10" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》审判监督程序若干问题的解释》第10条引用">[11]</a></sup>

<a id="art-201"></a>第二百零一条　人民法院根据被认定为无民事行为能力人、限制民事行为能力人本人、利害关系人或者有关组织的申请，证实该公民无民事行为能力或者限制民事行为能力的原因已经消除的，应当作出新判决，撤销原判决。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-351" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第351条引用">[1]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-352" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第352条引用">[2]</a></sup>

#### 第六节　认定财产无主案件

<a id="art-202"></a>第二百零二条　申请认定财产无主，由公民、法人或者其他组织向财产所在地基层人民法院提出。申请书应当写明财产的种类、数量以及要求认定财产无主的根据。

<a id="art-203"></a>第二百零三条　人民法院受理申请后，经审查核实，应当发出财产认领公告。公告满一年无人认领的，判决认定财产无主，收归国家或者集体所有。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-359" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第359条引用">[1]</a></sup>

<a id="art-204"></a>第二百零四条　判决认定财产无主后，原财产所有人或者继承人出现，在民法典规定的诉讼时效期间可以对财产提出请求，人民法院审查属实后，应当作出新判决，撤销原判决。

#### 第七节　确认调解协议案件

<a id="art-205"></a>第二百零五条　经依法设立的调解组织调解达成调解协议，申请司法确认的，由双方当事人自调解协议生效之日起三十日内，共同向下列人民法院提出：&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》审判监督程序若干问题的解释_20201229.md#art-1" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》审判监督程序若干问题的解释》第1条引用">[1]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》审判监督程序若干问题的解释_20201229.md#art-2" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》审判监督程序若干问题的解释》第2条引用">[2]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-417" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第417条引用">[3]</a></sup>

<a id="art-206"></a>第二百零六条　人民法院受理申请后，经审查，符合法律规定的，裁定调解协议有效，一方当事人拒绝履行或者未全部履行的，对方当事人可以向人民法院申请执行；不符合法律规定的，裁定驳回申请，当事人可以通过调解方式变更原调解协议或者达成新的调解协议，也可以向人民法院提起诉讼。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-373" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第373条引用">[1]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-374" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第374条引用">[2]</a></sup>

<a id="art-208"></a>第二百零八条　人民法院受理申请后，经审查，符合法律规定的，裁定拍卖、变卖担保财产，当事人依据该裁定可以向人民法院申请执行；不符合法律规定的，裁定驳回申请，当事人可以向人民法院提起诉讼。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/人民检察院民事诉讼监督规则_20210626.md#art-98" title="被《人民检察院民事诉讼监督规则》第98条引用">[1]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/人民检察院民事诉讼监督规则_20210626.md#art-99" title="被《人民检察院民事诉讼监督规则》第99条引用">[2]</a></sup>

### 第十六章　审判监督程序

<a id="art-209"></a>第二百零九条　各级人民法院院长对本院已经发生法律效力的判决、裁定、调解书，发现确有错误，认为需要再审的，应当提交审判委员会讨论决定。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/人民检察院民事诉讼监督规则_20210626.md#art-27" title="被《人民检察院民事诉讼监督规则》第27条引用">[1]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/人民检察院民事诉讼监督规则_20210626.md#art-29" title="被《人民检察院民事诉讼监督规则》第29条引用">[2]</a></sup>

<a id="art-210"></a>第二百一十条　当事人对已经发生法律效力的判决、裁定，认为有错误的，可以向上一级人民法院申请再审；当事人一方人数众多或者当事人双方为公民的案件，也可以向原审人民法院申请再审。当事人申请再审的，不停止判决、裁定的执行。

<a id="art-211"></a>第二百一十一条　当事人的申请符合下列情形之一的，人民法院应当再审：&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》审判监督程序若干问题的解释_20201229.md#art-17" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》审判监督程序若干问题的解释》第17条引用">[1]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-537" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第537条引用">[2]</a></sup>

<a id="art-212"></a>第二百一十二条　当事人对已经发生法律效力的调解书，提出证据证明调解违反自愿原则或者调解协议的内容违反法律的，可以申请再审。经人民法院审查属实的，应当再审。

<a id="art-213"></a>第二百一十三条　当事人对已经发生法律效力的解除婚姻关系的判决、调解书，不得申请再审。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-394" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第394条引用">[1]</a></sup>

<a id="art-214"></a>第二百一十四条　当事人申请再审的，应当提交再审申请书等材料。人民法院应当自收到再审申请书之日起五日内将再审申请书副本发送对方当事人。对方当事人应当自收到再审申请书副本之日起十五日内提交书面意见；不提交书面意见的，不影响人民法院审查。人民法院可以要求申请人和对方当事人补充有关材料，询问有关事项。

<a id="art-215"></a>第二百一十五条　人民法院应当自收到再审申请书之日起三个月内审查，符合本法规定的，裁定再审；不符合本法规定的，裁定驳回申请。有特殊情况需要延长的，由本院院长批准。

<a id="art-216"></a>第二百一十六条　当事人申请再审，应当在判决、裁定发生法律效力后六个月内提出；有[本法第二百一十一条](#art-211)第一项、第三项、第十二项、第十三项规定情形的，自知道或者应当知道之日起六个月内提出。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-413" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第413条引用">[1]</a></sup>

<a id="art-217"></a>第二百一十七条　按照审判监督程序决定再审的案件，裁定中止原判决、裁定、调解书的执行，但追索赡养费、扶养费、抚养费、抚恤金、医疗费用、劳动报酬等案件，可以不中止执行。

<a id="art-218"></a>第二百一十八条　人民法院按照审判监督程序再审的案件，发生法律效力的判决、裁定是由第一审法院作出的，按照第一审程序审理，所作的判决、裁定，当事人可以上诉；发生法律效力的判决、裁定是由第二审法院作出的，按照第二审程序审理，所作的判决、裁定，是发生法律效力的判决、裁定；上级人民法院按照审判监督程序提审的，按照第二审程序审理，所作的判决、裁定是发生法律效力的判决、裁定。

<a id="art-219"></a>第二百一十九条　最高人民检察院对各级人民法院已经发生法律效力的判决、裁定，上级人民检察院对下级人民法院已经发生法律效力的判决、裁定，发现有[本法第二百一十一条](#art-211)规定情形之一的，或者发现调解书损害国家利益、社会公共利益的，应当提出抗诉。

<a id="art-220"></a>第二百二十条　有下列情形之一的，当事人可以向人民检察院申请检察建议或者抗诉：&thinsp;<sup><a href="../民法商法/司法解释/最高人民法院关于审理票据纠纷案件若干问题的规定_20201229.md#art-33" title="被《最高人民法院关于审理票据纠纷案件若干问题的规定》第33条引用">[1]</a></sup>

<a id="art-221"></a>第二百二十一条　人民检察院因履行法律监督职责提出检察建议或者抗诉的需要，可以向当事人或者案外人调查核实有关情况。

<a id="art-222"></a>第二百二十二条　人民检察院提出抗诉的案件，接受抗诉的人民法院应当自收到抗诉书之日起三十日内作出再审的裁定；有[本法第二百一十一条](#art-211)第一项至第五项规定情形之一的，可以交下一级人民法院再审，但经该下一级人民法院再审的除外。

<a id="art-223"></a>第二百二十三条　人民检察院决定对人民法院的判决、裁定、调解书提出抗诉的，应当制作抗诉书。

<a id="art-224"></a>第二百二十四条　人民检察院提出抗诉的案件，人民法院再审时，应当通知人民检察院派员出席法庭。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于人民法院强制执行股权若干问题的规定_20211220.md#art-3" title="被《最高人民法院关于人民法院强制执行股权若干问题的规定》第3条引用">[1]</a></sup>

### 第十八章　公示催告程序

<a id="art-229"></a>第二百二十九条　按照规定可以背书转让的票据持有人，因票据被盗、遗失或者灭失，可以向票据支付地的基层人民法院申请公示催告。依照法律规定可以申请公示催告的其他事项，适用本章规定。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于在执行工作中如何计算迟延履行期间的债务利息等问题的批复_20090511.md#art-1" title="被《最高人民法院关于在执行工作中如何计算迟延履行期间的债务利息等问题的批复》第1条引用">[1]</a></sup>

<a id="art-230"></a>第二百三十条　人民法院决定受理申请，应当同时通知支付人停止支付，并在三日内发出公告，催促利害关系人申报权利。公示催告的期间，由人民法院根据情况决定，但不得少于六十日。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-127" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第127条引用">[1]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-457" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第457条引用">[2]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-458" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第458条引用">[3]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-459" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第459条引用">[4]</a></sup>

<a id="art-231"></a>第二百三十一条　支付人收到人民法院停止支付的通知，应当停止支付，至公示催告程序终结。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于执行担保若干问题的规定_20201229.md#art-1" title="被《最高人民法院关于执行担保若干问题的规定》第1条引用">[1]</a></sup>

<a id="art-232"></a>第二百三十二条　利害关系人应当在公示催告期间向人民法院申报。

<a id="art-233"></a>第二百三十三条　没有人申报的，人民法院应当根据申请人的申请，作出判决，宣告票据无效。判决应当公告，并通知支付人。自判决公告之日起，申请人有权向支付人请求支付。

<a id="art-234"></a>第二百三十四条　利害关系人因正当理由不能在判决前向人民法院申报的，自知道或者应当知道判决公告之日起一年内，可以向作出判决的人民法院起诉。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-301" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第301条引用">[1]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-302" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第302条引用">[2]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-421" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第421条引用">[3]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-422" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第422条引用">[4]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-462" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第462条引用">[5]</a></sup>

## 第三编　执行程序

### 第十九章　一般规定

<a id="art-235"></a>第二百三十五条　发生法律效力的民事判决、裁定，以及刑事判决、裁定中的财产部分，由第一审人民法院或者与第一审人民法院同级的被执行的财产所在地人民法院执行。

<a id="art-236"></a>第二百三十六条　当事人、利害关系人认为执行行为违反法律规定的，可以向负责执行的人民法院提出书面异议。当事人、利害关系人提出书面异议的，人民法院应当自收到书面异议之日起十五日内审查，理由成立的，裁定撤销或者改正；理由不成立的，裁定驳回。当事人、利害关系人对裁定不服的，可以自裁定送达之日起十日内向上一级人民法院申请复议。

<a id="art-237"></a>第二百三十七条　人民法院自收到申请执行书之日起超过六个月未执行的，申请执行人可以向上一级人民法院申请执行。上一级人民法院经审查，可以责令原人民法院在一定期限内执行，也可以决定由本院执行或者指令其他人民法院执行。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于人民法院办理仲裁裁决执行案件若干问题的规定_20180222.md#art-8" title="被《最高人民法院关于人民法院办理仲裁裁决执行案件若干问题的规定》第8条引用">[1]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于人民法院办理仲裁裁决执行案件若干问题的规定_20180222.md#art-10" title="被《最高人民法院关于人民法院办理仲裁裁决执行案件若干问题的规定》第10条引用">[2]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于人民法院办理仲裁裁决执行案件若干问题的规定_20180222.md#art-13" title="被《最高人民法院关于人民法院办理仲裁裁决执行案件若干问题的规定》第13条引用">[3]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于人民法院办理仲裁裁决执行案件若干问题的规定_20180222.md#art-14" title="被《最高人民法院关于人民法院办理仲裁裁决执行案件若干问题的规定》第14条引用">[4]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于人民法院办理仲裁裁决执行案件若干问题的规定_20180222.md#art-15" title="被《最高人民法院关于人民法院办理仲裁裁决执行案件若干问题的规定》第15条引用">[5]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于人民法院办理仲裁裁决执行案件若干问题的规定_20180222.md#art-16" title="被《最高人民法院关于人民法院办理仲裁裁决执行案件若干问题的规定》第16条引用">[6]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于审理仲裁司法审查案件若干问题的规定_20171226.md#art-17" title="被《最高人民法院关于审理仲裁司法审查案件若干问题的规定》第17条引用">[7]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于审理仲裁司法审查案件若干问题的规定_20171226.md#art-18" title="被《最高人民法院关于审理仲裁司法审查案件若干问题的规定》第18条引用">[8]</a></sup>&thinsp;<sup><a href="../民法商法/司法解释/最高人民法院关于审理劳动争议案件适用法律问题的解释（一）_20201229.md#art-24" title="被《最高人民法院关于审理劳动争议案件适用法律问题的解释（一）》第24条引用">[9]</a></sup>

<a id="art-238"></a>第二百三十八条　执行过程中，案外人对执行标的提出书面异议的，人民法院应当自收到书面异议之日起十五日内审查，理由成立的，裁定中止对该标的的执行；理由不成立的，裁定驳回。案外人、当事人对裁定不服，认为原判决、裁定错误的，依照审判监督程序办理；与原判决、裁定无关的，可以自裁定送达之日起十五日内向人民法院提起诉讼。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于公证债权文书执行若干问题的规定_20180930.md#art-12" title="被《最高人民法院关于公证债权文书执行若干问题的规定》第12条引用">[1]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于审理执行异议之诉案件适用法律问题的解释_20250723.md#art-1" title="被《最高人民法院关于审理执行异议之诉案件适用法律问题的解释》第1条引用">[2]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于审理执行异议之诉案件适用法律问题的解释_20250723.md#art-22" title="被《最高人民法院关于审理执行异议之诉案件适用法律问题的解释》第22条引用">[3]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-467" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第467条引用">[4]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-468" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第468条引用">[5]</a></sup>

<a id="art-239"></a>第二百三十九条　执行工作由执行员进行。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于执行和解若干问题的规定_20201229.md#art-10" title="被《最高人民法院关于执行和解若干问题的规定》第10条引用">[1]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于认可和执行台湾地区仲裁裁决的规定_20150629.md#art-19" title="被《最高人民法院关于认可和执行台湾地区仲裁裁决的规定》第19条引用">[2]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-470" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第470条引用">[3]</a></sup>

<a id="art-240"></a>第二百四十条　被执行人或者被执行的财产在外地的，可以委托当地人民法院代为执行。受委托人民法院收到委托函件后，必须在十五日内开始执行，不得拒绝。执行完毕后，应当将执行结果及时函复委托人民法院；在三十日内如果还未执行完毕，也应当将执行情况函告委托人民法院。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》执行程序若干问题的解释_20201229.md#art-22" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》执行程序若干问题的解释》第22条引用">[1]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-173" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第173条引用">[2]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-474" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第474条引用">[3]</a></sup>

<a id="art-241"></a>第二百四十一条　在执行中，双方当事人自行和解达成协议的，执行员应当将协议内容记入笔录，由双方当事人签名或者盖章。

<a id="art-242"></a>第二百四十二条　在执行中，被执行人向人民法院提供担保，并经申请执行人同意的，人民法院可以决定暂缓执行及暂缓执行的期限。被执行人逾期仍不履行的，人民法院有权执行被执行人的担保财产或者担保人的财产。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于对被执行人存在银行的凭证式国库券可否采取执行措施问题的批复_20201229.md#art-1" title="被《最高人民法院关于对被执行人存在银行的凭证式国库券可否采取执行措施问题的批复》第1条引用">[1]</a></sup>

<a id="art-243"></a>第二百四十三条　作为被执行人的公民死亡的，以其遗产偿还债务。作为被执行人的法人或者其他组织终止的，由其权利义务承受人履行义务。

<a id="art-244"></a>第二百四十四条　执行完毕后，据以执行的判决、裁定和其他法律文书确有错误，被人民法院撤销的，对已被执行的财产，人民法院应当作出裁定，责令取得财产的人返还；拒不返还的，强制执行。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-475" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第475条引用">[1]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-476" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第476条引用">[2]</a></sup>

<a id="art-245"></a>第二百四十五条　人民法院制作的调解书的执行，适用本编的规定。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-478" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第478条引用">[1]</a></sup>

<a id="art-246"></a>第二百四十六条　人民检察院有权对民事执行活动实行法律监督。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-440" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第440条引用">[1]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-466" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第466条引用">[2]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-515" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第515条引用">[3]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-518" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第518条引用">[4]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-545" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第545条引用">[5]</a></sup>

### 第二十章　执行的申请和移送

<a id="art-247"></a>第二百四十七条　发生法律效力的民事判决、裁定，当事人必须履行。一方拒绝履行的，对方当事人可以向人民法院申请执行，也可以由审判员移送执行员执行。

<a id="art-248"></a>第二百四十八条　对依法设立的仲裁机构的裁决，一方当事人不履行的，对方当事人可以向有管辖权的人民法院申请执行。受申请的人民法院应当执行。

<a id="art-249"></a>第二百四十九条　对公证机关依法赋予强制执行效力的债权文书，一方当事人不履行的，对方当事人可以向有管辖权的人民法院申请执行，受申请的人民法院应当执行。

<a id="art-250"></a>第二百五十条　申请执行的期间为二年。申请执行时效的中止、中断，适用法律有关诉讼时效中止、中断的规定。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于认可和执行台湾地区法院民事判决的规定_20241217.md#art-24" title="被《最高人民法院关于认可和执行台湾地区法院民事判决的规定》第24条引用">[1]</a></sup>

<a id="art-251"></a>第二百五十一条　执行员接到申请执行书或者移交执行书，应当向被执行人发出执行通知，并可以立即采取强制执行措施。

### 第二十一章　执行措施

<a id="art-252"></a>第二百五十二条　被执行人未按执行通知履行法律文书确定的义务，应当报告当前以及收到执行通知之日前一年的财产情况。被执行人拒绝报告或者虚假报告的，人民法院可以根据情节轻重对被执行人或者其法定代理人、有关单位的主要负责人或者直接责任人员予以罚款、拘留。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-497" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第497条引用">[1]</a></sup>

<a id="art-253"></a>第二百五十三条　被执行人未按执行通知履行法律文书确定的义务，人民法院有权向有关单位查询被执行人的存款、债券、股票、基金份额等财产情况。人民法院有权根据不同情形扣押、冻结、划拨、变价被执行人的财产。人民法院查询、扣押、冻结、划拨、变价的财产不得超出被执行人应当履行义务的范围。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于执行程序中计算迟延履行期间的债务利息适用法律若干问题的解释_20140707.md#art-1" title="被《最高人民法院关于执行程序中计算迟延履行期间的债务利息适用法律若干问题的解释》第1条引用">[1]</a></sup>

<a id="art-254"></a>第二百五十四条　被执行人未按执行通知履行法律文书确定的义务，人民法院有权扣留、提取被执行人应当履行义务部分的收入。但应当保留被执行人及其所扶养家属的生活必需费用。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-486" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第486条引用">[1]</a></sup>

<a id="art-255"></a>第二百五十五条　被执行人未按执行通知履行法律文书确定的义务，人民法院有权查封、扣押、冻结、拍卖、变卖被执行人应当履行义务部分的财产。但应当保留被执行人及其所扶养家属的生活必需品。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》执行程序若干问题的解释_20201229.md#art-23" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》执行程序若干问题的解释》第23条引用">[1]</a></sup>&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》执行程序若干问题的解释_20201229.md#art-26" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》执行程序若干问题的解释》第26条引用">[2]</a></sup>

<a id="art-256"></a>第二百五十六条　人民法院查封、扣押财产时，被执行人是公民的，应当通知被执行人或者他的成年家属到场；被执行人是法人或者其他组织的，应当通知其法定代表人或者主要负责人到场。拒不到场的，不影响执行。被执行人是公民的，其工作单位或者财产所在地的基层组织应当派人参加。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-493" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第493条引用">[1]</a></sup>

<a id="art-257"></a>第二百五十七条　被查封的财产，执行员可以指定被执行人负责保管。因被执行人的过错造成的损失，由被执行人承担。

<a id="art-258"></a>第二百五十八条　财产被查封、扣押后，执行员应当责令被执行人在指定期间履行法律文书确定的义务。被执行人逾期不履行的，人民法院应当拍卖被查封、扣押的财产；不适于拍卖或者当事人双方同意不进行拍卖的，人民法院可以委托有关单位变卖或者自行变卖。国家禁止自由买卖的物品，交有关单位按照国家规定的价格收购。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-500" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第500条引用">[1]</a></sup>

<a id="art-259"></a>第二百五十九条　被执行人不履行法律文书确定的义务，并隐匿财产的，人民法院有权发出搜查令，对被执行人及其住所或者财产隐匿地进行搜查。

<a id="art-260"></a>第二百六十条　法律文书指定交付的财物或者票证，由执行员传唤双方当事人当面交付，或者由执行员转交，并由被交付人签收。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国仲裁法》若干问题的解释_20060823.md#art-17" title="被《最高人民法院关于适用《中华人民共和国仲裁法》若干问题的解释》第17条引用">[1]</a></sup>

<a id="art-261"></a>第二百六十一条　强制迁出房屋或者强制退出土地，由院长签发公告，责令被执行人在指定期间履行。被执行人逾期不履行的，由执行员强制执行。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-515" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第515条引用">[1]</a></sup>

<a id="art-262"></a>第二百六十二条　在执行中，需要办理有关财产权证照转移手续的，人民法院可以向有关单位发出协助执行通知书，有关单位必须办理。

<a id="art-263"></a>第二百六十三条　对判决、裁定和其他法律文书指定的行为，被执行人未按执行通知履行的，人民法院可以强制执行或者委托有关单位或者其他人完成，费用由被执行人承担。

<a id="art-264"></a>第二百六十四条　被执行人未按判决、裁定和其他法律文书指定的期间履行给付金钱义务的，应当加倍支付迟延履行期间的债务利息。被执行人未按判决、裁定和其他法律文书指定的期间履行其他义务的，应当支付迟延履行金。

<a id="art-265"></a>第二百六十五条　人民法院采取[本法第二百五十三条](#art-253)、第二百五十四条、第二百五十五条规定的执行措施后，被执行人仍不能偿还债务的，应当继续履行义务。债权人发现被执行人有其他财产的，可以随时请求人民法院执行。

<a id="art-266"></a>第二百六十六条　被执行人不履行法律文书确定的义务的，人民法院可以对其采取或者通知有关单位协助采取限制出境，在征信系统记录、通过媒体公布不履行义务信息以及法律规定的其他措施。

## 第四编　涉外民事诉讼程序的特别规定

### 第二十三章　一般原则

<a id="art-270"></a>第二百七十条　在中华人民共和国领域内进行涉外民事诉讼，适用本编规定。本编没有规定的，适用本法其他有关规定。

<a id="art-271"></a>第二百七十一条　中华人民共和国缔结或者参加的国际条约同本法有不同规定的，适用该国际条约的规定，但中华人民共和国声明保留的条款除外。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-522" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第522条引用">[1]</a></sup>

<a id="art-272"></a>第二百七十二条　对享有外交特权与豁免的外国人、外国组织或者国际组织提起的民事诉讼，应当依照中华人民共和国有关法律和中华人民共和国缔结或者参加的国际条约的规定办理。

<a id="art-273"></a>第二百七十三条　人民法院审理涉外民事案件，应当使用中华人民共和国通用的语言、文字。当事人要求提供翻译的，可以提供，费用由当事人承担。

<a id="art-274"></a>第二百七十四条　外国人、无国籍人、外国企业和组织在人民法院起诉、应诉，需要委托律师代理诉讼的，必须委托中华人民共和国的律师。&thinsp;<sup><a href="../诉讼与非诉讼程序法/司法解释/最高人民法院关于适用《中华人民共和国民事诉讼法》的解释_20220401.md#art-532" title="被《最高人民法院关于适用《中华人民共和国民事诉讼法》的解释》第532条引用">[1]</a></sup>

<a id="art-275"></a>第二百七十五条　在中华人民共和国领域内没有住所的外国人、无国籍人、外国企业和组织委托中华人民共和国律师或者其他人代理诉讼，从中华人民共和国领域外寄交或者托交的授权委托书，应当经所在国公证机关证明，并经中华人民共和国驻该国使领馆认证，或者履行中华人民共和国与该所在国订立的有关条约中规定的证明手续后，才具有效力。

<a id="art-283"></a>第二百八十三条　人民法院对在中华人民共和国领域内没有住所的当事人送达诉讼文书，可以采用下列方式：

### 第二十六章　仲裁

<a id="art-288"></a>第二百八十八条　涉外经济贸易、运输和海事中发生的纠纷，当事人在合同中订有仲裁条款或者事后达成书面仲裁协议，提交中华人民共和国涉外仲裁机构或者其他仲裁机构仲裁的，当事人不得向人民法院起诉。

### 第二十七章　司法协助

<a id="art-293"></a>第二百九十三条　根据中华人民共和国缔结或者参加的国际条约，或者按照互惠原则，人民法院和外国法院可以相互请求，代为送达文书、调查取证以及进行其他诉讼行为。

<a id="art-294"></a>第二百九十四条　请求和提供司法协助，应当依照中华人民共和国缔结或者参加的国际条约所规定的途径进行；没有条约关系的，通过外交途径进行。

<a id="art-295"></a>第二百九十五条　外国法院请求人民法院提供司法协助的请求书及其所附文件，应当附有中文译本或者国际条约规定的其他文字文本。

<a id="art-296"></a>第二百九十六条　人民法院提供司法协助，依照中华人民共和国法律规定的程序进行。外国法院请求采用特殊方式的，也可以按照其请求的特殊方式进行，但请求采用的特殊方式不得违反中华人民共和国法律。

<a id="art-297"></a>第二百九十七条　人民法院作出的发生法律效力的判决、裁定，如果被执行人或者其财产不在中华人民共和国领域内，当事人请求执行的，可以由当事人直接向有管辖权的外国法院申请承认和执行，也可以由人民法院依照中华人民共和国缔结或者参加的国际条约的规定，或者按照互惠原则，请求外国法院承认和执行。

<a id="art-298"></a>第二百九十八条　外国法院作出的发生法律效力的判决、裁定，需要人民法院承认和执行的，可以由当事人直接向有管辖权的中级人民法院申请承认和执行，也可以由外国法院依照该国与中华人民共和国缔结或者参加的国际条约的规定，或者按照互惠原则，请求人民法院承认和执行。

<a id="art-299"></a>第二百九十九条　人民法院对申请或者请求承认和执行的外国法院作出的发生法律效力的判决、裁定，依照中华人民共和国缔结或者参加的国际条约，或者按照互惠原则进行审查后，认为不违反中华人民共和国法律的基本原则且不损害国家主权、安全、社会公共利益的，裁定承认其效力；需要执行的，发出执行令，依照本法的有关规定执行。

<a id="art-302"></a>第三百零二条　当事人向人民法院申请承认和执行外国法院作出的发生法律效力的判决、裁定，该判决、裁定涉及的纠纷与人民法院正在审理的纠纷属于同一纠纷的，人民法院可以裁定中止诉讼。

<a id="art-303"></a>第三百零三条　当事人对承认和执行或者不予承认和执行的裁定不服的，可以自裁定送达之日起十日内向上一级人民法院申请复议。

<a id="art-304"></a>第三百零四条　在中华人民共和国领域外作出的发生法律效力的仲裁裁决，需要人民法院承认和执行的，当事人可以直接向被执行人住所地或者其财产所在地的中级人民法院申请。被执行人住所地或者其财产不在中华人民共和国领域内的，当事人可以向申请人住所地或者与裁决的纠纷有适当联系的地点的中级人民法院申请。人民法院应当依照中华人民共和国缔结或者参加的国际条约，或者按照互惠原则办理。

<a id="art-305"></a>第三百零五条　涉及外国国家的民事诉讼，适用中华人民共和国有关外国国家豁免的法律规定；有关法律没有规定的，适用本法。

<a id="art-306"></a>第三百零六条　本法自公布之日起施行，《中华人民共和国民事诉讼法（试行）》同时废止。

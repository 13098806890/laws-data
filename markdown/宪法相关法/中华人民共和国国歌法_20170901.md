# 中华人民共和国国歌法

**分类**：法律  
**法律部门**：宪法相关法  
**公布日期**：2017-09-01  
**生效日期**：2017-10-01

> （2017年9月1日第十二届全国人民代表大会常务委员会第二十九次会议通过）

---

### 正文

<a id="art-1"></a>第一条　为了维护国歌的尊严，规范国歌的奏唱、播放和使用，增强公民的国家观念，弘扬爱国主义精神，培育和践行社会主义核心价值观，根据宪法，制定本法。

<a id="art-2"></a>第二条　中华人民共和国国歌是《义勇军进行曲》。

<a id="art-3"></a>第三条　中华人民共和国国歌是中华人民共和国的象征和标志。

<a id="art-4"></a>第四条　在下列场合，应当奏唱国歌：

<a id="art-5"></a>第五条　国家倡导公民和组织在适宜的场合奏唱国歌，表达爱国情感。

<a id="art-6"></a>第六条　奏唱国歌，应当按照本法附件所载国歌的歌词和曲谱，不得采取有损国歌尊严的奏唱形式。

<a id="art-7"></a>第七条　奏唱国歌时，在场人员应当肃立，举止庄重，不得有不尊重国歌的行为。

<a id="art-8"></a>第八条　国歌不得用于或者变相用于商标、商业广告，不得在私人丧事活动等不适宜的场合使用，不得作为公共场所的背景音乐等。

<a id="art-9"></a>第九条　外交活动中奏唱国歌的场合和礼仪，由外交部规定。

<a id="art-10"></a>第十条　在[本法第四条](#art-4)规定的场合奏唱国歌，应当使用国歌标准演奏曲谱或者国歌官方录音版本。

<a id="art-11"></a>第十一条　国歌纳入中小学教育。

<a id="art-12"></a>第十二条　新闻媒体应当积极开展对国歌的宣传，普及国歌奏唱礼仪知识。

<a id="art-13"></a>第十三条　国庆节、国际劳动节等重要的国家法定节日、纪念日，中央和省、自治区、直辖市的广播电台、电视台应当按照国务院广播电视主管部门规定的时点播放国歌。

<a id="art-14"></a>第十四条　县级以上各级人民政府及其有关部门在各自职责范围内，对国歌的奏唱、播放和使用进行监督管理。

<a id="art-15"></a>第十五条　在公共场合，故意篡改国歌歌词、曲谱，以歪曲、贬损方式奏唱国歌，或者以其他方式侮辱国歌的，由公安机关处以警告或者十五日以下拘留；构成犯罪的，依法追究刑事责任。

<a id="art-16"></a>第十六条　本法自2017年10月1日起施行。

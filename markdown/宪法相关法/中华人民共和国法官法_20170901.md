### 第一章　总则

<a id="art-1"></a>第一条　为了提高法官的素质，加强对法官的管理，保障人民法院依法独立行使审判权，保障法官依法履行职责，保障司法公正，根据宪法，制定本法。

<a id="art-2"></a>第二条　法官是依法行使国家审判权的审判人员，包括最高人民法院、地方各级人民法院和军事法院等专门人民法院的院长、副院长、审判委员会委员、庭长、副庭长、审判员和助理审判员。

<a id="art-3"></a>第三条　法官必须忠实执行宪法和法律，全心全意为人民服务。

<a id="art-4"></a>第四条　法官依法履行职责，受法律保护。

### 第五章　任免

<a id="art-11"></a>第十一条　法官职务的任免，依照宪法和法律规定的任免权限和程序办理。

<a id="art-12"></a>第十二条　初任法官采用考试、考核的办法，按照德才兼备的标准，从通过国家统一法律职业资格考试取得法律职业资格并且具备法官条件的人员中择优提出人选。

<a id="art-13"></a>第十三条　法官有下列情形之一的，应当依法提请免除其职务：

<a id="art-14"></a>第十四条　对于违反本法规定的条件任命法官的，一经发现，做出该项任命的机关应当撤销该项任命；上级人民法院发现下级人民法院法官的任命有违反本法规定的条件的，应当建议下级人民法院依法撤销该项任命，或者建议下级人民法院依法提请同级人民代表大会常务委员会撤销该项任命。

<a id="art-15"></a>第十五条　法官不得兼任人民代表大会常务委员会的组成人员，不得兼任行政机关、检察机关以及企业、事业单位的职务，不得兼任律师。

<a id="art-17"></a>第十七条　法官从人民法院离任后二年内，不得以律师身份担任诉讼代理人或者辩护人。

### 第七章　法官的等级

<a id="art-18"></a>第十八条　法官的级别分为十二级。

<a id="art-19"></a>第十九条　法官的等级的确定，以法官所任职务、德才表现、业务水平、审判工作实绩和工作年限为依据。

<a id="art-20"></a>第二十条　法官的等级编制、评定和晋升办法，由国家另行规定。

### 第八章　考核

<a id="art-21"></a>第二十一条　对法官的考核，由所在人民法院组织实施。

<a id="art-22"></a>第二十二条　对法官的考核，应当客观公正，实行领导和群众相结合，平时考核和年度考核相结合。

<a id="art-23"></a>第二十三条　对法官的考核内容包括：审判工作实绩，思想品德，审判业务和法学理论水平，工作态度和审判作风。重点考核审判工作实绩。

<a id="art-24"></a>第二十四条　年度考核结果分为优秀、称职、不称职三个等次。

<a id="art-25"></a>第二十五条　考核结果以书面形式通知本人。本人对考核结果如有异议，可以申请复议。

### 第九章　培训

<a id="art-26"></a>第二十六条　对法官应当有计划地进行理论培训和业务培训。

<a id="art-27"></a>第二十七条　国家法官院校和其他法官培训机构按照有关规定承担培训法官的任务。

<a id="art-28"></a>第二十八条　法官在培训期间的学习成绩和鉴定，作为其任职、晋升的依据之一。

### 第十章　奖励

<a id="art-29"></a>第二十九条　法官在审判工作中有显著成绩和贡献的，或者有其他突出事迹的，应当给予奖励。

<a id="art-30"></a>第三十条　法官有下列表现之一的，应当给予奖励：

<a id="art-31"></a>第三十一条　奖励分为：嘉奖，记三等功、二等功、一等功，授予荣誉称号。

### 第十一章　惩戒

<a id="art-32"></a>第三十二条　法官不得有下列行为：

<a id="art-33"></a>第三十三条　法官有本法第三十二条所列行为之一的，应当给予处分；构成犯罪的，依法追究刑事责任。

<a id="art-34"></a>第三十四条　处分分为：警告、记过、记大过、降级、撤职、开除。

<a id="art-35"></a>第三十五条　处分的权限和程序按照有关规定办理。

### 第十二章　工资保险福利

<a id="art-36"></a>第三十六条　法官的工资制度和工资标准，根据审判工作特点，由国家规定。

<a id="art-37"></a>第三十七条　法官实行定期增资制度。经考核确定为优秀、称职的，可以按照规定晋升工资；有特殊贡献的，可以按照规定提前晋升工资。

<a id="art-38"></a>第三十八条　法官享受国家规定的审判津贴、地区津贴、其他津贴以及保险和福利待遇。

### 第十三章　辞职辞退

<a id="art-39"></a>第三十九条　法官要求辞职，应当由本人提出书面申请，依照法律规定的程序免除其职务。

<a id="art-40"></a>第四十条　法官有下列情形之一的，予以辞退：

<a id="art-41"></a>第四十一条　辞退法官应当依照法律规定的程序免除其职务。

### 第十四章　退休

<a id="art-42"></a>第四十二条　法官的退休制度，根据审判工作特点，由国家另行规定。

<a id="art-43"></a>第四十三条　法官退休后，享受国家规定的养老保险金和其他待遇。

### 第十五章　申诉控告

<a id="art-44"></a>第四十四条　法官对人民法院关于本人的处分、处理不服的，自收到处分、处理决定之日起三十日内可以向原处分、处理机关申请复议，并有权向原处分、处理机关的上级机关申诉。

<a id="art-45"></a>第四十五条　对于国家机关及其工作人员侵犯本法第八条规定的法官权利的行为，法官有权提出控告。

<a id="art-46"></a>第四十六条　法官提出申诉和控告，应当实事求是。对捏造事实、诬告陷害的，应当依法追究其责任。

<a id="art-47"></a>第四十七条　对法官处分或者处理错误的，应当及时予以纠正；造成名誉损害的，应当恢复名誉、消除影响、赔礼道歉；造成经济损失的，应当赔偿。对打击报复的直接责任人员，应当依法追究其责任。

### 第十六章　法官考评委员会

<a id="art-48"></a>第四十八条　人民法院设法官考评委员会。

<a id="art-49"></a>第四十九条　法官考评委员会的组成人员为五至九人。

### 第十七章　附则

<a id="art-50"></a>第五十条　最高人民法院根据审判工作需要，会同有关部门制定各级人民法院的法官在人员编制内员额比例的办法。

<a id="art-51"></a>第五十一条　国家对初任法官实行统一法律职业资格考试制度，由国务院司法行政部门商最高人民法院等有关部门组织实施。

<a id="art-52"></a>第五十二条　对人民法院的执行员，参照本法有关规定进行管理。

<a id="art-53"></a>第五十三条　本法自1995年7月1日起施行。

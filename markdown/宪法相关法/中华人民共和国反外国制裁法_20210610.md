# 中华人民共和国反外国制裁法

**分类**：法律  
**法律部门**：宪法相关法  
**公布日期**：2021-06-10  
**生效日期**：2021-06-10

> （2021年6月10日第十三届全国人民代表大会常务委员会第二十九次会议通过）

---

### 正文

<a id="art-1"></a>第一条　为了维护国家主权、安全、发展利益，保护我国公民、组织的合法权益，根据宪法，制定本法。

<a id="art-2"></a>第二条　中华人民共和国坚持独立自主的和平外交政策，坚持互相尊重主权和领土完整、互不侵犯、互不干涉内政、平等互利、和平共处的五项原则，维护以联合国为核心的国际体系和以国际法为基础的国际秩序，发展同世界各国的友好合作，推动构建人类命运共同体。

<a id="art-3"></a>第三条　中华人民共和国反对霸权主义和强权政治，反对任何国家以任何借口、任何方式干涉中国内政。

<a id="art-4"></a>第四条　国务院有关部门可以决定将直接或者间接参与制定、决定、实施[本法第三条](#art-3)规定的歧视性限制措施的个人、组织列入反制清单。

<a id="art-7"></a>第七条　国务院有关部门依据[本法第四条](#art-4)至第六条规定作出的决定为最终决定。

<a id="art-8"></a>第八条　采取反制措施所依据的情形发生变化的，国务院有关部门可以暂停、变更或者取消有关反制措施。

<a id="art-9"></a>第九条　反制清单和反制措施的确定、暂停、变更或者取消，由外交部或者国务院其他有关部门发布命令予以公布。

<a id="art-10"></a>第十条　国家设立反外国制裁工作协调机制，负责统筹协调相关工作。

<a id="art-11"></a>第十一条　我国境内的组织和个人应当执行国务院有关部门采取的反制措施。

<a id="art-12"></a>第十二条　任何组织和个人均不得执行或者协助执行外国国家对我国公民、组织采取的歧视性限制措施。

<a id="art-13"></a>第十三条　对于危害我国主权、安全、发展利益的行为，除本法规定外，有关法律、行政法规、部门规章可以规定采取其他必要的反制措施。

<a id="art-14"></a>第十四条　任何组织和个人不执行、不配合实施反制措施的，依法追究法律责任。

<a id="art-15"></a>第十五条　对于外国国家、组织或者个人实施、协助、支持危害我国主权、安全、发展利益的行为，需要采取必要反制措施的，参照本法有关规定执行。

<a id="art-16"></a>第十六条　本法自公布之日起施行。

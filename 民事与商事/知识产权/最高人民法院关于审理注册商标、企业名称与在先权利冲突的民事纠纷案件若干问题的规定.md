# 最高人民法院关于审理注册商标、企业名称与在先权利冲突的民事纠纷案件若干问题的规定

**分类**：司法解释  
**法律部门**：民法商法  
**发布机关**：最高人民法院  
**发文字号**：法释〔2008〕3号  
**公布日期**：2008-02-18  
**生效日期**：2008-03-01

> 《最高人民法院关于审理注册商标、企业名称与在先权利冲突的民事纠纷案件若干问题的规定》已于2008年2月18日由最高人民法院审判委员会第1444次会议通过。现予公布，自2008年3月1日起施行。 2008年2月18日 最高人民法院 关于审理注册商标、企业名称与在先权利 冲突的民事纠纷案件若干问题的规定 法释〔2008〕3号 （2008年2月18日最高人民法院审判委员会第1444次会议通过　2008年2月18日最高人民法院公告公布　自2008年3月1日起施行）

---

### 正文

<a id="art-1"></a>第一条  原告以他人注册商标使用的文字、图形等侵犯其著作权、外观设计专利权、企业名称权等在先权利为由提起诉讼，符合[民事诉讼法第一百零八条](../../诉讼与司法程序/三大诉讼法/中华人民共和国民事诉讼法.md#art-108)规定的，人民法院应当受理。  
原告以他人使用在核定商品上的注册商标与其在先的注册商标相同或者近似为由提起诉讼的，人民法院应当根据[民事诉讼法第一百一十一条](../../诉讼与司法程序/三大诉讼法/中华人民共和国民事诉讼法.md#art-111)第（三）项的规定，告知原告向有关行政主管机关申请解决。但原告以他人超出核定商品的范围或者以改变显著特征、拆分、组合等方式使用的注册商标，与其注册商标相同或者近似为由提起诉讼的，人民法院应当受理。


<a id="art-2"></a>第二条  原告以他人企业名称与其在先的企业名称相同或者近似，足以使相关公众对其商品的来源产生混淆，违反[反不正当竞争法第五条](../../经济、税务与金融/贸易、竞争与市场/中华人民共和国反不正当竞争法.md#art-5)第（三）项的规定为由提起诉讼，符合[民事诉讼法第一百零八条](../../诉讼与司法程序/三大诉讼法/中华人民共和国民事诉讼法.md#art-108)规定的，人民法院应当受理。


<a id="art-3"></a>第三条  人民法院应当根据原告的诉讼请求和争议民事法律关系的性质，按照民事案件案由规定，确定注册商标或者企业名称与在先权利冲突的民事纠纷案件的案由，并适用相应的法律。


<a id="art-4"></a>第四条  被诉企业名称侵犯注册商标专用权或者构成不正当竞争的，人民法院可以根据原告的诉讼请求和案件具体情况，确定被告承担停止使用、规范使用等民事责任。

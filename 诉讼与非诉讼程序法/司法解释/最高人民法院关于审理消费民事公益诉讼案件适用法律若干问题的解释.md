# 最高人民法院关于审理消费民事公益诉讼案件适用法律若干问题的解释

**分类**：司法解释  
**法律部门**：诉讼与非诉讼程序法  
**发布机关**：最高人民法院  
**公布日期**：2020-12-29  
**生效日期**：2021-01-01

> 第1677次会议通过，根据2020年12月23日最高人民法院

---

### 正文

<a id="art-1"></a>第一条　中国消费者协会以及在省、自治区、直辖市设立的消费者协会，对经营者侵害众多不特定消费者合法权益或者具有危及消费者人身、财产安全危险等损害社会公共利益的行为提起消费民事公益诉讼的，适用本解释。

<a id="art-2"></a>第二条　经营者提供的商品或者服务具有下列情形之一的，适用[消费者权益保护法第四十七条](../../民法商法/中华人民共和国消费者权益保护法.md#art-47)规定：

<a id="art-3"></a>第三条　消费民事公益诉讼案件管辖适用《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》第二百八十五条的有关规定。

<a id="art-4"></a>第四条　提起消费民事公益诉讼应当提交下列材料：

<a id="art-5"></a>第五条　人民法院认为原告提出的诉讼请求不足以保护社会公共利益的，可以向其释明变更或者增加停止侵害等诉讼请求。

<a id="art-6"></a>第六条　人民法院受理消费民事公益诉讼案件后，应当公告案件受理情况，并在立案之日起十日内书面告知相关行政主管部门。

<a id="art-7"></a>第七条　人民法院受理消费民事公益诉讼案件后，依法可以提起诉讼的其他机关或者社会组织，可以在一审开庭前向人民法院申请参加诉讼。

<a id="art-8"></a>第八条　有权提起消费民事公益诉讼的机关或者社会组织，可以依据[民事诉讼法第八十一条](../../诉讼与非诉讼程序法/中华人民共和国民事诉讼法.md#art-81)规定申请保全证据。

<a id="art-9"></a>第九条　人民法院受理消费民事公益诉讼案件后，因同一侵权行为受到损害的消费者申请参加诉讼的，人民法院应当告知其根据[民事诉讼法第一百一十九条](../../诉讼与非诉讼程序法/中华人民共和国民事诉讼法.md#art-119)规定主张权利。

<a id="art-10"></a>第十条　消费民事公益诉讼案件受理后，因同一侵权行为受到损害的消费者请求对其根据[民事诉讼法第一百一十九条](../../诉讼与非诉讼程序法/中华人民共和国民事诉讼法.md#art-119)规定提起的诉讼予以中止，人民法院可以准许。

<a id="art-11"></a>第十一条　消费民事公益诉讼案件审理过程中，被告提出反诉的，人民法院不予受理。

<a id="art-12"></a>第十二条　原告在诉讼中承认对己方不利的事实，人民法院认为损害社会公共利益的，不予确认。

<a id="art-13"></a>第十三条　原告在消费民事公益诉讼案件中，请求被告承担停止侵害、排除妨碍、消除危险、赔礼道歉等民事责任的，人民法院可予支持。

<a id="art-14"></a>第十四条　消费民事公益诉讼案件裁判生效后，人民法院应当在十日内书面告知相关行政主管部门，并可发出司法建议。

<a id="art-15"></a>第十五条　消费民事公益诉讼案件的裁判发生法律效力后，其他依法具有原告资格的机关或者社会组织就同一侵权行为另行提起消费民事公益诉讼的，人民法院不予受理。

<a id="art-16"></a>第十六条　已为消费民事公益诉讼生效裁判认定的事实，因同一侵权行为受到损害的消费者根据[民事诉讼法第一百一十九条](../../诉讼与非诉讼程序法/中华人民共和国民事诉讼法.md#art-119)规定提起的诉讼，原告、被告均无需举证证明，但当事人对该事实有异议并有相反证据足以推翻的除外。

<a id="art-17"></a>第十七条　原告为停止侵害、排除妨碍、消除危险采取合理预防、处置措施而发生的费用，请求被告承担的，人民法院应依法予以支持。

<a id="art-18"></a>第十八条　原告及其诉讼代理人对侵权行为进行调查、取证的合理费用、鉴定费用、合理的律师代理费用，人民法院可根据实际情况予以相应支持。

<a id="art-19"></a>第十九条　本解释自2016年5月1日起施行。

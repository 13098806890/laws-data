# 最高人民法院关于国家赔偿案件立案工作的规定

**分类**：司法解释  
**法律部门**：诉讼与非诉讼程序法  
**发布机关**：最高人民法院  
**发文字号**：法释〔2012〕1号  
**公布日期**：2012-01-13  
**生效日期**：2012-02-15

> 最高人民法院《关于国家赔偿案件立案工作的规定》己于2011年12月26日由最高人民法院审判委员会第1537次会议通过，现予公布，自2012年2月15日起施行。

---

### 正文

<a id="art-1"></a>第一条　本规定所称国家赔偿案件，是指[国家赔偿法第十七条](../../宪法相关法/中华人民共和国国家赔偿法.md#art-17)、第十八条、第二十一条、第三十八条规定的下列案件：

<a id="art-2"></a>第二条　赔偿请求人向作为赔偿义务机关的人民法院提出赔偿申请，或者依照[国家赔偿法第二十四条](../../宪法相关法/中华人民共和国国家赔偿法.md#art-24)、第二十五条的规定向人民法院赔偿委员会提出赔偿申请的，收到申请的人民法院根据本规定予以审查立案。

<a id="art-3"></a>第三条　赔偿请求人当面递交赔偿申请的，收到申请的人民法院应当依照[国家赔偿法第十二条](../../宪法相关法/中华人民共和国国家赔偿法.md#art-12)的规定，当场出具加盖本院专用印章并注明收讫日期的书面凭证。

<a id="art-4"></a>第四条　赔偿请求人向作为赔偿义务机关的人民法院提出赔偿申请，收到申请的人民法院经审查认为其申请符合下列条件的，应予立案：

<a id="art-5"></a>第五条　赔偿请求人对作为赔偿义务机关的人民法院作出的是否赔偿的决定不服，依照[国家赔偿法第二十四条](../../宪法相关法/中华人民共和国国家赔偿法.md#art-24)的规定向其上一级人民法院赔偿委员会提出赔偿申请，收到申请的人民法院经审查认为其申请符合下列条件的，应予立案：

<a id="art-6"></a>第六条　作为赔偿义务机关的人民法院逾期未作出是否赔偿的决定，赔偿请求人依照[国家赔偿法第二十四条](../../宪法相关法/中华人民共和国国家赔偿法.md#art-24)的规定向其上一级人民法院赔偿委员会提出赔偿申请，收到申请的人民法院经审查认为其申请符合下列条件的，应予立案：

<a id="art-7"></a>第七条　赔偿请求人对行使侦查、检察职权的机关以及看守所、监狱管理机关作出的决定不服，经向其上一级机关申请复议，对复议机关的复议决定仍不服，依照[国家赔偿法第二十五条](../../宪法相关法/中华人民共和国国家赔偿法.md#art-25)的规定向复议机关所在地的同级人民法院赔偿委员会提出赔偿申请，收到申请的人民法院经审查认为其申请符合下列条件的，应予立案：

<a id="art-8"></a>第八条　复议机关逾期未作出复议决定，赔偿请求人依照[国家赔偿法第二十五条](../../宪法相关法/中华人民共和国国家赔偿法.md#art-25)的规定向复议机关所在地的同级人民法院赔偿委员会提出赔偿申请，收到申请的人民法院经审查认为其申请符合下列条件的，应予立案：

<a id="art-9"></a>第九条　人民法院应当在收到申请之日起七日内决定是否立案。

<a id="art-10"></a>第十条　赔偿请求人对复议机关或者作为赔偿义务机关的人民法院作出的决定不予受理的文书不服，依照[国家赔偿法第二十四条](../../宪法相关法/中华人民共和国国家赔偿法.md#art-24)、第二十五条的规定向人民法院赔偿委员会提出赔偿申请，收到申请的人民法院可以依照[本规定第六条](#art-6)、第八条予以审查立案。

<a id="art-11"></a>第十一条　自本规定施行之日起，《最高人民法院关于刑事赔偿和非刑事司法赔偿案件立案工作的暂行规定（试行）》即行废止；本规定施行前本院发布的司法解释与本规定不一致的，以本规定为准。

# 最高人民法院关于军事法院管辖民事案件若干问题的规定

**分类**：司法解释  
**法律部门**：诉讼与非诉讼程序法  
**发文字号**：法释〔2025〕6号  
**公布日期**：2025-04-25  
**生效日期**：2025-05-01

> （2025年3月1日最高人民法院审判委员会第1943次会议通过，自2025年5月1日起施行）

---

### 正文

<a id="art-1"></a>第一条　下列民事案件，由军事法院管辖：

<a id="art-2"></a>第二条　下列民事案件，有关军事法院与地方人民法院都有权管辖，地方当事人向军事法院提起诉讼的，军事法院应当受理：

<a id="art-3"></a>第三条　当事人一方是军人或者军队单位，且合同履行地或者标的物所在地在营区内的合同或者其他财产权益纠纷，当事人书面约定军事法院管辖，不违反法律关于级别管辖、专属管辖和专门管辖规定的，应当由军事法院管辖。

<a id="art-4"></a>第四条　军事法院受理第一审民事案件，应当参照民事诉讼法关于级别管辖、地域管辖的规定确定。

<a id="art-5"></a>第五条　军事法院发现受理的民事案件属于地方人民法院管辖的，应当移送有管辖权的地方人民法院，受移送的地方人民法院应当受理。

<a id="art-6"></a>第六条　军事法院与地方人民法院依照[本规定第五条](#art-5)移送管辖之前，可以先行协商。

<a id="art-7"></a>第七条　军事法院受理案件后，当事人对管辖权有异议的，应当在提交答辩状期间提出。军事法院对当事人提出的异议，应当审查。异议成立的，裁定将案件移送有管辖权的军事法院或者地方人民法院；异议不成立的，裁定驳回。

<a id="art-8"></a>第八条　本规定所称军人是指中国人民解放军的现役军官、军士、义务兵及具有军籍的学员，中国人民武装警察部队的现役警官、警士、义务兵及具有军籍的学员。军队中的文职人员、由军队管理的离退休人员、具有军队编制的职工，参照军人确定管辖。

<a id="art-9"></a>第九条　本规定自2025年5月1日起施行。《最高人民法院关于军事法院管辖民事案件若干问题的规定》（2020年修正）同时废止；本规定施行前的司法解释以及司法解释性文件与本规定不一致的，以本规定为准。
